# C3M1 Firmware v0.1.15 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本带来**全链路机内黑白胶片模式（`COLOR MODE`）**、**内部 Flash 快门计数 1,022 槽磨损均衡（`COUNTER FMT`）**、**1X 取景融合 64 级暗角提速（`LENS VIG = +1.15` 稳跑 `9–10 fps`）**、**亏电休眠 60 Hz 走时与回电 `≥ 25%` 无缝切回普通休眠**、**24 组实测驱动的 11 点分段休眠电量曲线**，以及**取景与全屏回看 50% 半透明无顶线底栏 + 3×3 构图线全屏贯通**。本版本净回收 **`3,616 B` `.bss`**（`56,176 B → 52,560 B`，物理栈余量增至 `~19.4 KB`），全程零软浮点、峰值栈严守 `< 6 KB` 红线，并已通过四模型交叉只读代码审计与实机验证。

## 核心更新

### 1. 全链路机内黑白胶片模式（`COLOR MODE`，`schema v19`）
- **菜单第 1 项新增 `COLOR MODE`**（`COLOR / B&W / B&W HI / B&W RED`，`FILE FORMAT` 顺延至第 3 项），复用 `C3M1.CFG` 末尾 1 B 保留 48 B 结构体与无损升级。
- **取景器 64 级严格中性 RGB565 胶片 S 曲线**：零偏绿灰阶映射，保留彩色对焦峰值与后台正常 AWB/AE 测光，左上角实时显示 `BW / BW+ / BWR` 标识。
- **直出单通道灰度 Baseline JPEG（`SOF0 Nf=1`）**：跳过彩色 CCM，采用线性光正权重混色并在 S 曲线前执行保颗粒柔和亮度 NR；DNG 保持 100% 无损彩色 Bayer RAW 并写 IFD0 `0x010E` 影调标记与黑白 4×4 嵌入缩略图，回看 1X/4X 按单文件自动还原对应黑白影调与单通道高感降噪。

### 2. 内部 Flash 快门计数磨损均衡与 `COUNTER FMT` 切换（`-2,048 B .bss`）
- **`0x08070000` 快门页自动识别与 1,022 槽追加写**：页尾 `"C3WL"` 魔数自动区分原厂单槽（`STOCK`）与磨损均衡格式（`WEAR-LVL`，寿命 > 1,000 万次）；翻页先写新页 `slot[0]` 再写魔数防断电丢计数，补充全路径 `HAL_FLASH_*` 状态检查、回读校验与 `0xFFFF` 空槽防护。
- **`FORMAT SD` 下方新增 `COUNTER FMT` 开关**：支持 `STOCK → WEAR-LVL` 零擦除原地升级与 `WEAR-LVL → STOCK` 100% 原厂单槽还原，`SYSTEM INFO` 同步展示当前格式与已用槽位；移除 `g_flashbuf[1024]` 净省 `2,048 B` `.bss`。

### 3. 1X 取景融合 64 级暗角提速 & 标配 `6mm F1.6` 暗角定标（`-1,568 B .bss`）
- **标配 `6mm F1.6` 预设暗角定标（实验 7）**：经全对焦行程漫射平场与叠合 `WarpRectilinear (-0.072)` 验证，将预设 `.vignette` 由 `0` 更新为 **`23`（`+1.15`）**。
- **融合解马赛克 64 级暗角优化**：将暗角增益代数融合进 `vf_chroma_vig_pack_rgb565`（单周期 `MUL + USAT ASR`）与黑白 S 曲线前缩放，移除第二遍后处理与 `1.5 KB` 查表；实机验证 `LENS VIG = +1.15` 下 1X 取景由 `8 fps` 恢复至 **`9–10 fps`**，且暗角过渡由 16 档细腻提升至 64 级。

### 4. 亏电休眠 60 Hz 走时自动恢复 & 休眠电量分段重标定
- **亏电休眠 60 Hz 走时与回电 `≥ 25%` 无缝切回普通休眠**：`<3.20V` 亏电休眠改用 8 MHz HSI + `TIM6` 60 Hz（`+10 ppm`）驱动 3 s 双闪并持续推进软件时钟（期间不做 SD 热插拔检测，交由切入普通休眠后再监测）；每 3 s 以 `~1.1 ms` 零 PLL 8 MHz HSI ADC（`adc_battery_sample_hsi8_mv()`）巡检轻载电量，连续 2 次（6 s）确认达到 **`≥ 25%`**（`~3.56V`）即在息屏状态下零闪烁、零递归无缝交接至普通呼吸灯休眠（覆盖开机、取景与唤醒全部 3 个入口）。
- **休眠轻载 11 点分段电量曲线重标定（实验 5 增补至 26 组实测）**：基于 24 组「稳定工作 → 立即休眠」实测揭示的锂电 U 型内阻特征（两端 `≤ 3.45V` / `≥ 3.91V` 压差 `+50 mV`，中段 `3.50–3.84V` 稳定 `+30 mV`），将 `adc_mv_to_percent_light()` 升级为独立 11 点轻载标定表（`3300 / 3430 / 3530 / 3580 / 3620 / 3660 / 3710 / 3770 / 3850 / 3960 / 4050 mV`），全工作段误差收敛至 `≤ ±1%`（中位 `0%`）并精确对齐红黄边界。

### 5. 取景与全屏回看 50% 半透明无顶线底栏 + 3×3 构图线贯通
- **主界面取景**：底栏背景透出度由 `25%` 提升至 **`50%`**（零额外 CPU 开销），移除底栏上端灰色横线，1X 抗锯齿同步覆盖底栏 20 px 区域；3×3 构图竖线延伸至屏幕最底端 `y = 239` 并先绘制于底栏之下，呈现自然的半透明压暗层次。
- **全屏回看同步满屏 `320×240`**：1X（`CLEAN`/`CLIP`）与 4X `ZOOM`（含 DNG 18-bit RGB666 与 JPEG RGB565 全路径）升级为完整 `320×240` + 同款 **50% 半透明无顶线底栏**（复用 `s_osd_bar_buf` 保持 0 B `.bss` 与峰值栈 `< 6 KB`，提示字提亮至浅银 `0xD69A` 保可读）。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.15.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.15.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.15.hex`（或 `c3m1_camera_v0.1.15.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，`TP4056` 无 Power-Path 负载分离电路；实测样机在自动休眠与亏电休眠下外接充电均可正常跳绿灯自动停充，但因器件公差仍不排除个体机身无法截止或微循环浮充风险，日常长时间充电仍建议先长按 `ASA` 休眠落盘时间，再**拨断物理电源开关 `SW4`**。
- 主板 AL422B `/RE` 引脚硬接地且 `Q2 (AMS1117-3.3V)` 输出电容 `C34` 仅 `1 µF`，固件严格保持非并发帧锁（`g_vsync_state == 2`）以确保零错色成像。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数存内部 Flash 只增不减，支持 `STOCK / WEAR-LVL` 无损切换，固件不提供任何计数清零功能。
