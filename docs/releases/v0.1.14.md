# C3M1 Firmware v0.1.14 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本带来**全链路统一抗锯齿管线（1X 监看 U1 混色 / DNG 4×4 缩略图 / JPEG Malvar 5×5）**、**1X 监看全组合稳跑 `9–10 fps` 性能优化**，以及**直出 VGA JPEG 与 DNG 1X/4X 回看 ISO 自适应机内高感降噪（`HIGH ISO NR`）**，全量改动 **0 B `.bss` 增长、0 软浮点**，并已通过四模型交叉只读代码审计与实机验证。

## 核心更新

### 1. 统一抗锯齿管线与菜单开关（`schema v18`，48 B 无损迁移）
- **新增 `ANTI-ALIASING` 与 `HIGH ISO NR` 持久化开关**（均默认 `ON`，兼容旧 `schema v16/v17` 配置无损迁移）。
- **1X 实时监看 + 快门定格预览 U1 抗锯齿**：在 `INCAM DISTORT = OFF / ON` 两条路径上统一启用行间 32-bit SWAR 50/50 混色，消除横向/斜线抽样锯齿；峰值对焦仅叠于 `y0` 保持 1 px 锐利红/黄/白/蓝轮廓线。
- **DNG 嵌入缩略图 & 直出 JPEG 画质升级**：
  - DNG `160×120` IFD0 缩略图升级为 **`4×4` 线性光全区域盒式下采样**，消除回看 1X 抽样锯齿与摩尔纹；
  - 直出 VGA JPEG 常规路径升级为 **20 行滑动 Bayer 条带 + Malvar-He-Cutler 5×5 纯整数梯度修正解马赛克**，有效压制斜线拉链锯齿与红蓝伪色边。

### 2. 1X 监看全组合稳跑 `9–10 fps` 性能优化
- **零 `memcpy` 均衡 U1 DMA 与 Thumb-2 混色加速**：复用 `scratch` 尾部第 3 槽 `peak_g[2]` 实现 `y0` 原地直接发 DMA 且 `y0/y1` 均衡重叠，配合 `LDRD/STRD` 8 像素展开 `vf_avg_row_be()`（约 `2.99 ms / 110` 行）。
- **畸变矫正内层循环重排**：`vf_warp_row_1x()` 引入 11 节点水平对称复用与 0 栈溢出 4 px 循环（减少 `648 B` Flash、省约 `4 ms`/帧）。
- **实机帧率验收**：`INCAM DISTORT (ON/OFF) × ANTI-ALIASING (ON/OFF)` 全部 4 种组合均稳跑 **`9–10 fps`**，`4X` 对焦放大维持 **`8 fps`**。

### 3. 直出 VGA JPEG 三级 ISO 自适应高感降噪（`HIGH ISO NR`）
- **覆盖畸变矫正开/关全路径，纯整数零除法（`0 B .bss` 增长）**：
  - **`ISO ≤ 200`（100 / 125 / 160 / 200）或关闭**：100% 旁路原路径，宿主实测 ISO 100 / 200 产出与原固件**逐字节完全一致**；
  - **`ISO 250–320`**：仅执行轻度 Stage 2A 色度联合双边滤波，完整保留 Malvar 5×5 与全部亮度细节；
  - **`ISO 400–640`（画质优先）**：继续保留完整 Malvar 5×5 解马赛克，叠加 Stage 1 8-bit Gamma 域热/冷像素剔除 + 轻度查表色度/暗部增强亮度双边 + 温和融合 DCT AC 柔缩；
  - **`ISO 800–3200`**：自动切回平滑 3×3 双线性解马赛克避免放大噪点，三级降噪随 ISO 平滑渐进至满档（暗部 `Y < -48` 增强压噪、亮部与硬边锐利保留）。
- **热路径零除法优化**：Stage 2A（`>> 6` 查表）与 Stage 2B（`>> 4` 查表）热循环 **0 条 `sdiv/udiv`**、Stage 3 融合入量化单遍完成；实拍固定 ISO 1600 + 机内畸变开启下观感干净且 `DNG+JPG` 存卡回归 `5–8 s` 基线区间。

### 4. DNG 回看机内高感降噪（1X + 4X 放大）
- **按 DNG EXIF `ISO` 与 `HIGH ISO NR` 开关实时生效（不修改 SD 卡上的 DNG 文件）**：可随时在菜单切换开关对比同一张历史高感 DNG 的降噪前后效果；`ISO ≤ 200`、关闭或无 ISO 元数据时 100% 旁路。
- **全格式覆盖与 18-bit RGB666 保持**：
  - **1X 缩略图**：复用 `scratch` 尾部 `2,400 B` 缓存执行 3-tap H/V 亮度引导色度联合双边（ISO ≥ 800 叠轻度暗部亮度双边）后再 2× 双线性放大送 18-bit RGB666 DMA1；
  - **4X 1:1 放大（畸变/非畸变、8-bit/16-bit HDR 全覆盖）**：`noinline` 兄弟帧隔离防栈叠加，执行 Stage 1 8-bit 热像素剔除 + 2×2 5-tap 色度联合双边 + 全分辨率 3-tap 暗部增强亮度双边；内联 `cam12→sRGB8`、`pb_chroma_row_t` 连续排布与单周期 `__SSAT`/`__USAT` 融合 RGB666 抖动并恢复 8-bit 畸变 16 行批量读卡，保持跟手缩放与平移响应。
- **链接脚本栈下限保护**：`STM32F103ZETX_FLASH.ld` 将 `_Min_Stack_Size` 由 `4 KB` 提升至 `6 KB`（`0x1800`），实测 JPEG 与回看峰值栈链均低于 `6 KB` 且保留 `> 10 KB` 物理余量。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.14.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.14.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.14.hex`（或 `c3m1_camera_v0.1.14.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，电源开关闭合时休眠电池侧仍余约 `~45 mA` 静态电流，且 `TP4056` 无 Power-Path 负载分离电路；**请务必先长按 `ASA` 休眠落盘时间，再拨断物理电源开关后充电或长时间存放**。
- 主板 AL422B `/RE` 引脚硬接地且 `Q2 (AMS1117-3.3V)` 输出电容 `C34` 仅 `1 µF`，固件严格保持非并发帧锁（`g_vsync_state == 2`）以确保零错色成像。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
