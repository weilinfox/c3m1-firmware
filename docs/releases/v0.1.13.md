# C3M1 Firmware v0.1.13 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本带来**全链路机内镜头畸变与暗角矫正（1X 监看 / 快门定格预览 / 直出 JPEG / DNG 缩略图 / DNG 4X 回看 `OpcodeList3`）**、**镜头预设与 `DRIVE MODE` 连拍/包围曝光**、**取景器/存卡/回放第一梯队性能优化与 Flash/栈瘦身**，以及**四模型交叉代码审计全部高/中危项闭环加固**。

## 核心更新

### 1. 全链路镜头矫正与镜头预设（`schema v16 / v17`，48 B 无损迁移）
- **新增 `LENS PROFILE` 镜头预设**：内置 `UNKNOWN` 与 `6mm F1.6`（原装镜头实测标定 `kr1 = -0.072`），选中自动填充焦距、光圈、畸变与暗角，并在 DNG / JPEG 同步写入标准 EXIF `LensModel (0xA434)`；手动修改焦距/光圈偏离预设时自动切回 `UNKNOWN`，微调畸变/暗角则保留预设。
- **新增 `INCAM DISTORT` 机内畸变总开关（默认 `OFF`）**：
  - `OFF`：仅写入 DNG `OpcodeList3 (0xC74E)` 元数据，机内零额外几何开销；
  - `ON`：同步驱动 **1X 实时监看**、**快门定格预览帧**、**直出 VGA JPEG**（单遍线性光 2D R/B + G 梅花菱形双线性采样）以及 **DNG / HDR 嵌入缩略图**。
- **DNG 4X 放大回看原生解析 `OpcodeList3 (0xC74E)`**：直接从每个 DNG 文件自身 SubIFD 纯整数解码拍摄时写入的 `FixVignetteRadial` 与 `WarpRectilinear`（不依赖当前菜单镜头设置、零软浮点），采用 35 行水平裁剪环形缓存 + 16 像素分段线性插值实时矫正 8-bit 普通 DNG 与 16-bit HDR DNG，保持 18-bit RGB666 DMA1 双缓冲输出与完整 GRBG 相位。

### 2. 拍摄模式扩展（`DRIVE MODE`）与快门跟手度优化
- **新增运行态 `DRIVE MODE`（`SINGLE / BURST / AEB 3F`，不写配置）**：支持长按快门连续连拍（`BURST`）以及免倒计时 3 张独立包围曝光（`AEB 3F`：`0EV / -2EV / +2EV`，输出 `_0/_1/_2.{dng,jpg}`，不受 `DEL HDR BRK` 影响）。
- **低时滞快门触发与所见即所得定格帧**：`KEYSHOT` 改为前沿瞬时触发（释放侧 30 ms 消抖防回弹），并在取景渲染每 16 行中段响应早退；按下快门先锁存 AL422B 精确单帧并立即将带畸变/暗角矫正的定格画面绘至屏幕后再执行写卡，确保屏幕定格帧与 SD 卡落盘文件为同一帧。

### 3. 取景器、拍照存卡、回放与系统资源性能优化
- **取景器纯软件提速（严守 AL422B 非并发帧锁，零错色）**：基于 `AL422B.pdf` 与主板原理图确认 `/RE` 接地、128 B 缓存与 `C34 = 1 µF` 三项硬件约束后，恢复严格 `g_vsync_state == 2` 锁帧彻底根除偶发蓝色错色；随后通过 16 段径向暗角 LUT、小端 `vf_ring` + `-O3` 行指针外提 `vf_warp_row_1x`、4X 4 字节对齐 `s_raw_row_buf[648]` + 4× 展开 `fifo_read_bytes` + 32-bit `raw_demosaic_1x1_to_buf` 及默认关闭 1 Hz 阻塞串口打印，实测非零 `LENS VIG` 下稳定达到 **`1X 9–10 fps / 4X 8 fps`**。
- **拍照存卡与回放提速**：
  - VGA JPEG 编码器全文件 `-O2` + 自然序 Q16 倒数量化表（热路径 0 除法）+ `__builtin_clz` + 像素色域与位流全内联；
  - DNG Pass 1 按 `4,096 B`（8 扇区对齐）切分并保留 `256 B` 尾块，Pass 2 复用空闲 `s_bayer_strip` 按 `30,720 B`（60 扇区）批量落盘（`CMD25` 写卡次数由 76 次降至 10+1 次）；实测 `DNG+JPG` 单拍由 `5–6 s` 收敛至稳定 **`5 s`**；
  - 回放升级 `c3m1_jdec` `-O2` + `2048 B` 输入缓冲 + `stream_getc` 内联快路径、640×480 JPEG `320×8` 条带 DMA、DNG 1X / INFO / 4X 批量 `f_read` + 18-bit RGB666 DMA1 双缓冲（读卡前同步防 AHB 争抢）、以及 JSR 目录单遍 `f_opendir/f_readdir` 扫描。
- **零风险 Flash / RAM / 栈瘦身**：裁剪未使用的 32pt 字库 `asc2_3216`（`-6,080 B` Flash）；以纯整数 IEEE-754 编解码彻底清零 `__aeabi_d*/f*` 软浮点库；`hsram1` 局部化（`-72 B .bss`）；HDR 合并 `FIL tf[3]` 复用 `scratch` 尾部（`-1,776 B` 峰值栈，`0 B .bss`）。

### 4. 电量曲线对齐与四模型代码审计加固
- **工作 / 休眠电量曲线对齐**：将工作态 `0%` 对齐禁写 SD 临界电压 `3.25V`（`3.25–4.00V`），休眠轻载曲线统一采用 `+50 mV` 偏移（`3.30–4.05V`）。
- **稳定性与边界加固**：四模型交叉审计并修复 `BOOT CLOCK = OFF` 与热插卡时钟恢复、`c3m1_cfg_load` 纯只读 + 低电禁写修复、`c3m1_jdec` `DRI/RSTm` 填充与 IDCT 中间值防溢出、`SD_DATATIMEOUT = 2000 ms` + `HAL_GetTick()` 1,000 ms 超时、`vsync_reset_idle` / `wait_vsync_state` 原子化与 `SENSOR TIMEOUT!` 保护、`TIM6` 仅休眠启停、`USART1` 纯 TX 防悬空 RX 中断、`STM32F103ZETX_FLASH.ld` 显式锁定 `448 KB`（严守 `0x08070000` 快门计数页），以及 4X 畸变环形缓存防超前驱逐与外部畸形 DNG 边界防护。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.13.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.13.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.13.hex`（或 `c3m1_camera_v0.1.13.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，电源开关闭合时休眠电池侧仍余约 `~45 mA` 静态电流，且 `TP4056` 无 Power-Path 负载分离电路；**请务必先长按 `ASA` 休眠落盘时间，再拨断物理电源开关后充电或长时间存放**。
- 主板 AL422B `/RE` 引脚硬接地且 `Q2 (AMS1117-3.3V)` 输出电容 `C34` 仅 `1 µF`，固件严格保持非并发帧锁（`g_vsync_state == 2`）以确保零错色成像。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
