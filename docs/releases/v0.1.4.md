# C3M1 Firmware v0.1.4 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本为常驻 RAW 取景器带来三项微单级辅助工具：**索尼微单风格常驻 1px 峰值对焦（4 色可选）、64 档实时迷你直方图（含高光截断红线警示）与 1X 半透明三分构图线**，全部内联在 DMA 刷屏行缓冲中完成，零闪烁且低开销。

## 核心更新

### 1. 索尼微单风格常驻 2D 峰值对焦（`PEAK COLOR`）
- **常驻开启，4 色可选**：菜单新增 `PEAK COLOR`（`RED / YELLOW / WHITE / BLUE`，默认 `RED`，选项文字实时以高亮色预览），`1X` 全视野与 `4X` 放大对焦均生效。
- **1px 细丝轮廓与抗噪优化**：采用水平 1px 非极大值抑制（NMS）与随 ISO 自适应抬高的阈值过滤虚焦与高 ISO 噪点；并通过 `256 B` `s_lut_g6` 查表 + 双行乒乓缓冲消除二次解包与 `memcpy`，兼顾清晰度与帧率（实机 10~12 fps）。

### 2. 64 档实时迷你直方图（`HISTOGRAM`）
- 菜单新增 `HISTOGRAM`（`ON / OFF`，默认 `ON`），在取景右下角 `y = 192..217` 渲染 `66×26 px` 暗底直方图与 1/4 档刻度线。
- 将 RGB565 5-bit R/B 扩展至完整 6-bit（`0..63`）计算感知亮度分布，覆盖完整 64 格动态范围；画面高光截断 >2% 时右侧边框与高光柱亮红警示。

### 3. 半透明三分构图线（`GRID 3X3`）与配置升级
- 菜单新增 `GRID 3X3`（`OFF / ON`，默认 `OFF`），在 `1X` 取景模式叠加 50% 半透明 1px 三分线，`4X` 放大对焦时自动隐藏。
- 二进制配置 `0:CAYE_CFG/c3m1.cfg` 保持 32 字节定长，结构版本升级至 `schema v2`，旧版本配置首次开机自动安全迁移重建。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.4.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.4.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.4.hex`（或 `c3m1_camera_v0.1.4.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 机身无 RTC 硬件，文件修改日期固定为 `2026-12-26`，DNG `DateTime` 标签固定为 `2026:08:17 00:00:00`。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
