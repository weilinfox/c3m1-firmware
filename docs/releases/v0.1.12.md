# C3M1 Firmware v0.1.12 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本带来**真 16-bit 4 帧机内流式 HDR 合成（`16B 4F`）**、**`JSR BURST` 三脚架超分连拍与回看整组管理**、**镜头焦距 / 光圈 EXIF 元数据与 DNG 1.4 `OpcodeList3` 镜头畸变/暗角矫正**，以及**工作态/休眠轻载双电量百分比曲线标定**。

## 核心更新

### 1. 真 16-bit 4 帧机内 HDR（`16B 4F`）
- **`HDR MERGE` 新增 `16B 4F`（`-3 / -1 / +1 / +3 EV`）**：相邻帧恒定 2 EV 重叠、总跨度 64× 填满 16-bit 线性空间，零额外 `.bss` 流式融合；实测同场景动态范围由单帧 10-bit 的 `9.32 EV` 逐级提升至 `12B 2F` `11.16–11.47 EV`、`14B 3F` `12.69–13.15 EV`、`16B 4F` **`14.13–14.60 EV`**（详见 `docs/ov7725_experiments.md` 实验三）。
- **新增 `DEL HDR BRK` 菜单开关（默认 `OFF`）**：开启后，独立 HDR 在 `_hdr` 合成完毕后自动删除 `_0.._3` 包围单帧；组合 `JSR BURST` 时在整组亮帧与黑场全部拍完合成完毕后统一清理。

### 2. JSR 三脚架超分连拍模式（`JSR BURST`）与回看整组支持
- **运行态 `JSR BURST`（`OFF / 7F / 14F / 30F`，不写配置）**：与 `HDR MERGE` 正交组合（支持 10/12/14/16-bit 连拍序列，左上角显示 `JSR7/14/30` 或 `H16x14`）；3 秒可取消脚架倒计时后锁曝光/ISO/白平衡并归档至 `CAYE_CAM/YYYYMMDD/CDIxxxxx_7/_14/_30/`，组合 HDR 时首帧锁定整组 `WhiteLevel` 与 `BaselineExposure`。
- **匹配黑场拍摄引导**：亮帧拍完后全屏弹窗 `JSR DARK FRAME / COVER LENS COMPLETELY`，提示完全遮挡镜头后按快门拍摄同参数 `CDIyyyyy_dark.dng`（按 `ASA` 可跳过）；文档同步提供各 ISO 与 HDR 档的 JSR 满阱容量（$e^-$）参考表。
- **回看完整支持 JSR 连拍目录**：自动扫描并将每个 JSR 连拍子目录折叠为 1 条回看记录（以首张代表亮帧支持 1X / CLIP / INFO / 4X 放大预览），底栏与 `INFO` 页以品红色标注具体拍摄类型（如 `JSR 14F`、`J14 H16` / `JSR 14F H16`），`INFO` 页汇总实际亮帧数、黑场完整性与整组体积，删图弹出 `DELETE JSR SET?` 整组删除。

### 3. 镜头 EXIF 元数据与 DNG 1.4 `OpcodeList3` 镜头矫正（`schema v15`）
- **新增 `LENS FOCAL`（默认 `6mm`）与 `LENS APERTURE`（默认 `F0`）**：位于 `MIN AUTO SHT` 正下方、`LENS DIST / VIG` 上方，结构体直接存原始值（`44 B` schema v15，支持从旧版 40 B v10–v14 自动无损迁移）：
  - `LENS FOCAL`：`OFF` 与 `4mm ~ 500mm` 共 39 档常见镜头原始标称焦距（弹窗同步显示官方 `9×` 等效焦距，如 `6mm (EQ 54mm)`、`4mm (EQ 36mm)`，`4X` 一键复位 `6mm`）；非 `OFF` 时在 DNG 与 JPEG 同步写入标准 EXIF `FocalLength (0x920A)` 与 `FocalLengthIn35mmFilm (0xA405)`。
  - `LENS APERTURE`：`F0` ~ `F32.0`（步进 `0.1`，`4X` 归零 `F0`）；按相机惯例在 DNG 与 JPEG 始终写入标准 EXIF `FNumber (0x829D)`（`F0` 写入 `0/1`）。
  - 回看 `INFO` 页同步解析并在曝光栏显示光圈（`F0` / `F2.8` / 旧片 `F--`）、在日期栏右侧显示原始焦距与 `9×` 等效焦距（如 `FL 6mm (EQ 54mm)`）。
- **新增 `LENS DIST` 与 `LENS VIG`（DNG 1.4 `OpcodeList3 (0xC74E)`）**：
  - `LENS DIST`（`-0.200 ~ +0.200`，步进 `0.002`，默认 `0`）：非零时写入大端序标准 `OpcodeList3 (0xC74E)` 单平面 `WarpRectilinear`（自带 4:3 最大内接无黑边 `maxfov` 缩放，C3M1 原装镜头实测甜点 `-0.072`），Lightroom / ACR 打开自动生效且保留无损 Bayer RAW。
  - `LENS VIG`（`0 ~ +2.50`，步进 `0.05`，默认 `0`）：非零时写入 `FixVignetteRadial`（先于畸变执行）并在机内直出 JPEG 与 DNG 缩略图线性域同步补偿（JSR 黑场自动跳过）。

### 4. 工作态 / 休眠轻载双电量曲线与实验文档完善
- **工作态与休眠轻载双曲线对齐**：实测 9 组工作/休眠压差数据后，将取景带载曲线标定为 `3.20–4.00V`、休眠速览专属轻载曲线 `adc_mv_to_percent_light()` 标定为 `3.30–4.05V`，彻底消除工作与休眠速览间的百分比和警示色跳变。
- **实验记录完善**：在 `docs/ov7725_experiments.md` 补齐实验三（HDR 动态范围）、实验四（LCD 刷新率与撕裂）、实验五（双电量曲线实测）、实验六（畸变标定、光心偏心与 `maxfov` 对比），并全篇清晰标注 `[实测]` / `[脚本统计]` / `[估算/理论]` 来源。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.12.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.12.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.12.hex`（或 `c3m1_camera_v0.1.12.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，电源开关闭合时休眠电池侧仍余约 `~45 mA` 静态电流，且 `TP4056` 无 Power-Path 负载分离电路；**请务必先长按 `ASA` 休眠落盘时间，再拨断物理电源开关后充电或长时间存放**。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
