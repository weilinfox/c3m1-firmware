# C3M1 Firmware v0.1.11 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本带来**机内 12-bit / 14-bit 多帧流式 HDR 合成**、**DNG/JPEG 完整 EXIF 曝光参数写入与回看 `INFO` 展示**、**取景色彩与 HUD 焕新**、**`4X` 放大波轮按键防卡死修复**，以及完整的**低电强制休眠、带载电量曲线与休眠最轻载电量速览**体系。

## 核心更新

### 1. 机内 12-bit / 14-bit 多帧流式 HDR 合成（`HDR MERGE`）
- **运行态菜单项（默认 `OFF`，不写配置）**：菜单新增 `HDR MERGE`（`OFF` / `12B 2F` / `14B 3F`），关机自动复位 `OFF`；开启时左上角模式显示青色 `H12` / `H14`。
- **恒定 ISO 纯快门包围 + 3 秒可取消自拍倒计时**：按下快门后进入 3 秒脚架防抖倒计时（`LED1` 自拍提示，期间按 `ASA` / `4X` 可随时取消）；拍摄全程锁定当前 ISO、仅调节快门积分行数完成 `2F (-1/+1 EV → 真 12-bit DNG)` 或 `3F (-2/0/+2 EV → 真 14-bit DNG)` 包围与零额外 `.bss` 流式融合。
- **同组文件归档与快门计数**：保留全部单帧包围片（`CDIxxxxx_0/_1[/_2].dng`）与合成片（`CDIxxxxx_hdr.dng`，带 `BaselineExposure` 与色调映射 `160×120` 预览图），快门计数按实际曝光帧数累加（`2F` +2、`3F` +3）。
- **OV7725 时序与高光色相加固**：根除向上增曝光 510 行过渡帧 bug 与 `DM_LN` 长哑行提前锁存截断；在 CCM 前将白平衡高光钳位至中性白点 `wb_ceil`，彻底解决 HDR 1X/4X 回看过曝偏色及直方图高光未顶头问题。

### 2. 完整 EXIF 曝光参数写入 & 回看体验升级
- **DNG / JPEG 同步写入 `ExifIFD`**：写入 `ExposureTime`（快门）、`ISOSpeedRatings`（ISO）、`ExposureBiasValue`（曝光补偿）与 `DateTimeOriginal / DateTimeDigitized`；HDR 单帧 `_0/_1/_2` 自动叠加各自实际包围 EV 偏移，`_hdr.dng` 保留基准 `EXP COMP`。
- **回看 `INFO` 新增 `EXP` 曝光行**：6 行紧凑信息区新增 `1/100s  ISO 200  +0.0EV  WB 5500K` 展示，兼容小端/大端 EXIF 解析。
- **新增 `PB SKIP BRK` 菜单开关（`schema v11`，无损兼容 `v10`）**：位于 `BOOT CLOCK` 下方，默认 `OFF`；开启后若同组存在 `_hdr` 合成片，回看自动跳过 `_0/_1/_2` 直接浏览 `_hdr`（缺失 `_hdr` 时仍保留单帧可见）。
- **过片扳手统一删图**：回看 1X 全图与 4X 放大视图均支持短拨过片扳手弹出删图确认窗。

### 3. 色彩管线、透明左上角 HUD 与 `4X` 操控修复
- **取景色彩升级**：新增 Filmic S-Curve LUT、取景饱和度增益与更鲜明准确的 OV7725 CCM。
- **左上角透明计数与模式标识**：取景左上角无暗底内联叠加卡剩余可拍张数（`>99999` 5 位封顶）与当前模式（`DNG` / `D+J` / `JPG` / `H12` / `H14`）；快门计数移入 `DEBUG INFO`（`FPS: xx` / `SHT: xxxxx` 双行对齐）。
- **根治 `4X` 放大波轮锁死与漏按键**：在 `ov7725_camera_refresh()` 每 16 行中段轮询顶板按键与 BCD 波轮（`~9–11 ms` 周期）并将 `DIAL_STALE_GAP_MS` 放宽至 `250 ms`，显著提升 `1X / 4X` 按键与波轮跟手度。

### 4. 四档低电保护、`< 3.20V` 低电强制休眠与休眠电量速览
- **菜单低电提示修复**：电池 `< 3.25V` 锁定 SD 写入时，菜单底栏明确显示红色 **`LOW BAT`**（不再误报 `SD ERR`）。
- **`< 3.20V` 低电强制休眠**：覆盖开机拦截、取景连续 2 次 2 s 采样与普通休眠唤醒三处入口——先弹窗 **15 s**（`LOW BATTERY! / x.xxV - SLEEPING (NOT OFF) / SWITCH OFF TO CHARGE / LED BLINK = POWER STILL ON`），息屏后 `LED1` 每 3 s 短双闪（4% 占空比，明显区别于普通休眠呼吸灯）提示电源开关未断，按任意顶键可复显 **5 s** 最轻载实时电压。
- **实机带载电量曲线（`3.20V = 0%` ～ `4.00V = 100%`）**：针对 C3M1 ~400 mA 取景带载压降重新标定 10 段百分比曲线，并将黄字预警微调对齐至 `3.52V（~25%）`。
- **普通休眠最轻载电量速览（零残影）**：休眠呼吸灯态按下 `ASA` 之外的任意顶键（`SHOT` / `4X` / 过片扳手），在保持 OV7725 休眠且点亮背光之前采集最轻载电压，于纯黑屏右下角按 HUD 样式同时显示 **`x.xxV xxx%`** 3 秒后自动回睡（期间按 `ASA` 立即唤醒，进休眠前清黑 GRAM 并等 1 帧刷新后再亮背光，彻底无残影）。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.11.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.11.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.11.hex`（或 `c3m1_camera_v0.1.11.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，电源开关闭合时休眠电池侧仍余约 `~45 mA` 静态电流，且 `TP4056` 无 Power-Path 负载分离电路；**请务必先长按 `ASA` 休眠落盘时间，再拨断物理电源开关后充电或长时间存放**。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
