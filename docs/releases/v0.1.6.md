# C3M1 Firmware v0.1.6 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本补齐微单日常拍摄体验的核心拼图：**机内照片回看（1X 极速预览 + 1:1 放大平移 + DNG/JPG 联动删图）、底栏 0.1 EV 实时测光表、±3 EV（1/3 EV 步进）微单标尺曝光补偿，以及可独立开关的直方图上方 `FPS` 调试信息**，同时加固热插卡配置读取并修复高速自动快门显示截断。

## 核心更新

### 1. 机内照片回看（Playback）与 1:1 像素放大
- **过片扳手双功能**：短拨松手保持原本的过片上弦功能；**长按 ≥ 600 ms** 进入照片回看，永远从最新一张开始，自动合并同编号 `DNG+JPG` 为单张条目（最多索引最新 1,024 张，复用现有 `11.3 KB` 条带缓冲，零新增 `.bss` 静态 RAM）。
- **全格式兼容与极速解码**：
  - 1X 浏览（居中 `294×220` 无畸变 4:3 全图）：新 DNG 直接双线性缩放内嵌 `160×120` 预览图（~65 ms），自动兼容历史无预览老 DNG（2×2 流式解拜耳）与纯 VGA Baseline JPEG（内置纯整数流式 `c3m1_jdec` 解码器）。
  - **1:1 放大检查**：按 `4X` 进入中心 `1:1` 放大（DNG 直解全尺寸 Bayer RAW 3×3 裁切，JPG 按视口 ROI 跳过解码并早停），右上角叠加迷你视口定位框；**波轮**上下平移、**`ASA`** 向左、**快门**向右，再按 **`4X`** 退回 1X 回看。
- **安全删图与退出**：1X 态短按 **`ASA`** 弹出二次确认删图窗（波轮切 `NO/YES`、快门确认、`ASA`/扳手取消；确认后**同时删除同名 `.DNG` 与 `.JPG`**，`<3.25V` 低电保护禁删）；1X 态**短拨过片扳手**退出回看返回取景。

### 2. 底栏 0.1 EV 实时测光表 & ±3 EV 曝光补偿（`EXP COMP`）
- **实时测光 EV 显示**：利用移出帧率后腾出的底栏空间，在 ISO 与白平衡之间新增 **带一位小数的实时测光 EV 偏差**（`-5.0EV ~ +3.0EV`，相对 18% 线性灰），手动 M 档与自动档均实时生效，白 / 黄 / 红 / 青多色直观提示欠曝、过曝或补偿状态。
- **±3 EV 曝光补偿（`EXP COMP`）**：菜单第 3 项新增 `EXP COMP`（`-3.0EV ~ +3.0EV`，`1/3 EV` 步进共 19 档），按快门弹出微单风格 **`-3 .. 0 .. +3` 刻度标尺窗**（波轮左右微调、`4X` 一键归零、快门保存、`ASA` 取消），直接驱动 Q4 精度软件闭环 AE。

### 3. `DEBUG INFO` 开关、底栏布局修复与热插卡加固
- **调试信息独立开关（`DEBUG INFO`）**：菜单 `FORMAT SD` 下方、`SYSTEM INFO` 上方新增 `DEBUG INFO`（`OFF / ON`，默认 `OFF`）；开启后在直方图正上方内联零闪烁显示完整 **`FPS: xx`**，关闭时界面保持清爽。
- **底栏快门防截断**：扩宽快门显示区域至 10 字符（60 px），完整显示 `SA:1/23000` / `SA:1/11500`。
- **SD 热插卡配置保护**：热插卡挂载前暂停 OV7725 FIFO 写入防止 VSYNC 中断干扰 SDIO，区分瞬态 `CFG_LOAD_IO_ERR` 并自动延时重试，读错时绝不覆写卡内原有有效配置。
- 二进制配置 `0:CAYE_CFG/c3m1.cfg` 保持 32 字节定长，结构升级至 `schema v6`（升级至 `v0.1.6` 首次开机自动安全重建默认配置）。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.6.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.6.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.6.hex`（或 `c3m1_camera_v0.1.6.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 机身无 RTC 硬件，文件修改日期固定为 `2026-12-26`，DNG `DateTime` 标签固定为 `2026:08:17 00:00:00`。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
