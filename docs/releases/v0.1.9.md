## 核心更新

### 1. 回看 1X 过曝 / 过暗区域标注与 4X 过片手柄快捷退出
- **1X 过曝 / 欠曝斜纹标注**：回看 1X 全图浏览（新 DNG 嵌入预览、历史老 DNG 解拜耳、纯 JPEG 1X 均生效）自动以 **45° 亮红斜纹标注过曝区域（RGB ≥ 250）**、**亮蓝斜纹标注死黑欠曝区域（RGB ≤ 4）**，零额外 RAM 开销；按 `4X` 进入 1:1 放大看细节时不叠加标注，保持纯净像素。
- **4X 放大态直接退出回看**：在 1:1 放大态下拨动过片扳手（`FILMKEY`）可直接退出回看返回取景，底栏同步更新提示 `DIAL:UD A/S:LR 4X:1X LEV:ESC`。

### 2. 配置跨版本无缝保留 & 开机设时拨盘防误跳
- **跨版本保留用户配置**：`0:CAYE_CFG/c3m1.cfg` 校验改为基于 `struct_size` + `magic` + `schema_ver` + CRC-32 + 字段范围（移除 `fw_major/minor/patch` 强一致拒载）；从 `v0.1.8` 升级至 `v0.1.9`（同为 `schema v10`）将**完整保留所有菜单设置与上次保存的时间**，不再重置。
- **修复开机设时年份偶发自跳**：`SET DATE (1/2)` 入口调整为先完成 `key_init_state()` 与 50 ms BCD 拨盘消抖稳定后再锁存 `last_dial`，彻底消除上电瞬态引发的年份自跳。

### 3. 深度代码审查安全与稳定性修复
- **慢门 `AUTO` 预览增益补偿**：当 `MIN AUTO SHT` 设为 `1/25`、`1/15` 或 `1/8`（`auto_aec > 500`）时，`AUTO` 预览保持 `15 fps` 并自动叠加硬件 `GAIN` + 数字 LUT 亮度补偿，解决暗光 AE 跑飞及成片比预览过曝的问题。
- **休眠唤醒与拔卡加固**：唤醒时先恢复 `SysTick` 再切回 72 MHz HSE/PLL（防止低电 HSE 起振超时死等）；休眠循环同步监测 `SDOK`，休眠期间拔/换卡时唤醒后自动卸载并交由热插拔安全重挂。
- **编解码器与 SDIO 边界加固**：`c3m1_jdec` 补全 Huffman Kraft 码空间越界校验、拦截非 `1×1` 灰度 MCU 并升级 ROI 坐标至 `uint32_t`；`playback` 的 DNG 解析改用无溢出减法边界校验并要求 Bayer RAW `≥ 2×2`，钳位小尺寸外部 JPEG 放大迷你框；`c3m1_jpeg` `io_err` 短路、`sd_diskio` 忙等拔卡快退及 `sdio` 死循环隐患一并清除。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.9.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.9.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.9.hex`（或 `c3m1_camera_v0.1.9.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，`SW4` 闭合时休眠电池侧仍余约 `~45 mA` 静态电流；建议关机前先**长按 `ASA` 休眠落盘时间**，再拨断物理开关 `SW4`。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
