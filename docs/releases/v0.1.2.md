# C3M1 Firmware v0.1.2 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本完成 **OV7725 传感器底层画质双重大升级**，全部经实机对照实验与 Adobe Camera Raw 验证通过：**单张 DNG 体积减半（310 KB）、写卡提速 2×，同时暗部有效精度反超原厂至 2.6 倍，并彻底根除热机高 ISO 洋红暗部雾霾**。

## 核心更新

### 1. OV7725 片内 10-bit → 8-bit Gamma 压扩与 310 KB 自动还原 DNG
- **更小文件、更高暗部精度（310 KB vs 原厂 618 KB）**：
  - 原厂固件（`618 KB`）每个像素白补 1 字节 `0x00` 塞进 16-bit 容器，一半体积是无效零填充，实际有效精度仅线性 8-bit（丢弃了 OV7725 10-bit ADC 低 2 bit）。
  - 本版本通过 7 组硬件对照实验证实清零 `COM7 Bit 4`（改为 `COM7 = 0x01`、`DSP_Ctrl1 = 0x87`、`DSP_Ctrl4 = 0x02`）可在 RAW 模式下开启真 10-bit 域片内 Gamma 压扩，暗部灰阶精细度实测提升至原厂的 **2.62 倍**（暗部 `1..16` 展开为 `1..42` 连续无空洞 42 级）。
  - 取消无效零填充改为紧凑 8-bit 封装，并在 `1,120 B` DNG 文件头内嵌 512 B 标准 `LinearizationTable`（Tag `0xC618`），Adobe Camera Raw / Lightroom 自动线性还原，**单张体积降至 `310,240 B`、写 SD 卡速度直接翻倍**。

### 2. OV7725 硬件 ABLC 抗温漂（`COM13 = 0xE6`）与 12-bit 分通道动态黑电平
- **消除热机高 ISO 洋红雾霾**：冷机（18.4°C）vs 热机全黑暗帧实测证实，原厂关闭 BLC（`COM13 = 0x00`）在热机 `ISO 1600` 下底噪暴涨 `+120` LSB（`G≈82 / R=B≈126`，损失约 12% 动态范围并呈严重洋红偏色）；开启 **`COM13 = 0xE6`** 硬件光学暗像元 ABLC 后，冷热温漂压死在 `±1.5` LSB 以内。
- **消除极端拉曝光暗部偏绿**：将 `LinearizationTable` 升级至 **12-bit 精度（`0..4064`，`WhiteLevel = 4064`，0 额外体积）**，按拍照 ISO 动态写入分通道 `GRBG BlackLevel`（`ISO 100: (25, 23, 23, 25)` .. `ISO 1600: (85, 91, 91, 85)`），极端拉曝光无偏绿/偏紫。
- **取景监看与测光同步升级**：`s_inv_gamma_12[256]` 一表三用，取景 LUT 升级为 4-bit 分数插值 sRGB（保持 **15F 零帧率损耗**、暗部监看更顺滑），`1X` / `4X` 的 AE 与 Gray-World AWB 均在线性光域分通道扣黑。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.2.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.2.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.2.hex`（或 `c3m1_camera_v0.1.2.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 机身无 RTC 硬件，文件修改日期固定为 `2026-12-26`，DNG `DateTime` 标签固定为 `2026:08:17 00:00:00`。
- `NUMRST (PA3)` 物理按键暂不做支持，后续统一改由机内菜单 `RESET COUNT` 提供。
