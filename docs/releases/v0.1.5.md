# C3M1 Firmware v0.1.5 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本带来完整的机内直出影像管线与色彩校准升级：**标准 DNG 嵌入 `160×120` 预览图、纯整数流式 VGA Baseline JPEG 直出与同帧 `DNG+JPG` 双出、OV7725 DNG/JPEG 统一色彩矩阵与动态 `AsShotNeutral` 校准、白平衡色温预设与底栏实时色温读数，以及 `MAX AUTO ISO` 扩展至 `3200`**。

## 核心更新

### 1. 标准 DNG 嵌入预览图 + 机内流式 VGA JPEG 直出（`FILE FORMAT`）
- **DNG 多 IFD 嵌入预览图**：采用标准 DNG 1.4 `IFD0`（`160×120` 校准 sRGB 缩略图，~57.6 KB，复用 4 KB/行缓冲零额外 RAM）+ `SubIFD`（全尺寸 `644×480` 8-bit 自动线性化 Bayer RAW），单张总大小约 `367 KB`，macOS / Windows 文件管理器可直接缩略预览，并为后续机内照片回看奠定基础。
- **纯整数流式 VGA JPEG 编码器**：新增无浮点软编管线（`18×644 B` 条带 3×3 双线性去马赛克 + 12-bit 线性扣黑 + 3×3 CCM + IJG 整数 DCT），直出 `640×480` YCbCr 4:2:0 Q90 Baseline JPEG（仅增 ~4.1 KB Flash / ~11.3 KB 条带缓冲）。
- **菜单首项 `FILE FORMAT`**：支持 `DNG`（默认）/ `DNG+JPG` / `JPG`；选择 `DNG+JPG` 时利用 AL422B `/RRST` 读指针复位，实现严格同一帧曝光的 DNG 与 JPEG 同帧双出。

### 2. OV7725 统一色彩校准（DNG `ColorMatrix1` + `AsShotNeutral` & JPEG CCM）
- 修复原厂 DNG `ColorMatrix1` 红蓝响应比例倒置导致 Adobe Camera Raw「原照设置」色温偏绿/偏黄的问题，替换为基于 OV7725 实测白响应与 Bradford 色适应校准的 `D65` `ColorMatrix1`，并按每张照片实测白平衡动态写入 `AsShotNeutral (0xC628)`。
- 直出 JPEG 3×3 色彩校正矩阵与 DNG 矩阵严格互逆对齐，实机对比 DNG「原照设置」与直出 JPEG 色彩一致性大幅提升。

### 3. 白平衡色温预设（`WHITE BAL`）与底栏实时色温显示
- 菜单第二项新增 **`WHITE BAL`**，按色温从低到高排列为 **`AUTO` / `3200K`（灯光卷）/ `5500K`（普通胶片）/ `6500K`（日光卷）**（默认 `AUTO`），固定预设增益基于 `ColorMatrix1` 精确反算，同步作用于实时取景、DNG `AsShotNeutral` 与直出 JPEG。
- 底部状态栏第三项新增**实时白平衡色温显示**：自动白平衡以白色显示实时估算色温（如 `A5500K`），锁定预设时以黄色显示设定值（`3200K` / `5500K` / `6500K`）。

### 4. `MAX AUTO ISO` 扩展至 `3200` 与配置升级
- `MAX AUTO ISO` 新增 **`3200`** 档位（`400 / 800 / 1600 / 3200`，默认 `1600`），对应 OV7725 硬件最高 `31×` 增益，底部状态栏自动 ISO 读数同步扩展至 `3200`（手动 `ASA` 仍保持最高 `1600`）。
- 二进制配置 `0:CAYE_CFG/c3m1.cfg` 保持 32 字节定长，结构版本升级至 `schema v4`（因固件版本号升级至 `v0.1.5`，首次开机将自动安全重建默认配置）。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.5.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.5.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.5.hex`（或 `c3m1_camera_v0.1.5.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 机身无 RTC 硬件，文件修改日期固定为 `2026-12-26`，DNG `DateTime` 标签固定为 `2026:08:17 00:00:00`。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
