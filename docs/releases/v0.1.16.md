# C3M1 Firmware v0.1.16 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本为四模型全量深度审查与底层性能/功耗专项打磨版本：升级 **4-bit SDIO `DMA2_Channel4` 24.0 MHz**（绕开 STM32F103 HWFC 勘误与多项 HAL 竞态并配 4 级自动探底回退及 `SYSTEM INFO` `SD BUS` 屏显）、落地 **两阶段 500 kHz / 20 Hz 深度休眠 + 休眠彻底关断 SD**、补齐 **全模态电源看门狗与坏卡/无卡分级菜单救卡**、**根治暖光/`3200K` 高光青斑与 `B&W RED` 亮部封顶不足**，并完成取景解马赛克、HDR、JPEG、回看与生产态日志的全链路优化（静态 RAM `bss = 53,192 B`，峰值栈 `5,496 B < 6,144 B`，0 软浮点、0 `malloc`，固件体积详见文末 CI 构建表，全部改动均经四模型交叉只读复验 `PASS`）。

## 核心更新

### 1. 4-bit SDIO 升级 `DMA2_Channel4` 24.0 MHz 与 `SD BUS` 屏显
- **彻底解决 STM32F103 SDIO 高速读写失败与 HAL 竞态**：关闭存在 ES0340 §2.8.1 毛刺勘误的硬件流控（`HWFC = DISABLE`），启用空闲的 `DMA2_Channel4`（与 LCD `DMA1_Channel1` 零冲突），规避 `HAL_DMA_IRQHandler` 遗留 `DMA_CCR_EN=1` 导致半双工写方向切换失效的缺陷；采用同抢占分级 `SDIO_IRQn (1,0)` / `DMA2_Channel4_5_IRQn (1,1)` 杜绝 `CMD12` 重入卡死，并补齐末块 `DCRCFAIL`/`DATAEND` 优先锁存、`RXACT` 判错与 512 B 非对齐缓冲中转。
- **四级自动探底降频与屏显**：`MX_SDIO_SD_Init()` 按 **`24.0 MHz (0x01) → 18.0 MHz (0x02) → 12.0 MHz (0x04) → 9.0 MHz (0x06)`** 阶梯执行双次多块 DMA 读取 + FNV-1a 校验；`SYSTEM INFO` 新增 **`SD BUS`** 行实时显示当前频率与 `(FB)` 回退状态。
- **三卡实机压测与选卡结论**（压测工具留档于独立提交 `ea5c62c`）：SanDisk Ultra 16GB SDHC、TF 转接 Lexar GOLD 128GB UHS-II、Fanxiang K520 128GB UHS-II 免重启热插拔多轮复测全档位 100% PASS，24 MHz 较 9 MHz 裸读提速 **+45%~+55%**、FatFs 读提速 **+34%~+46%**、FatFs 写提速 **+19%~+25%**；受 3.3V Default Speed 与 4 KB 短写限制，整机持续写速上限约 `1.2–1.4 MB/s`（**低于 C4 级别**）：**已有正规老牌 C4 / C6 卡即可满足带宽，新购选市面最入门的正规大厂 C10 / U1 / A1 卡即已彻底跑满（`A1` 更利于 4 KB 短写稳定性），购买 U3/V30/UHS-II 不会提速**。

### 2. 两阶段 500 kHz 深度休眠 + 休眠彻底关闭 SD
- **休眠彻底关 SD（休眠期 0 SD 轮询，唤醒自动刷新）**：进休眠落盘时间与配置后，立即 `f_mount(NULL, "0:", 0)` → 发 `CMD0` 使 SD 卡进入最低功耗 Idle → `MX_SDIO_SD_DeInit()` 关 `SDIO`/`DMA2` 时钟并将 `PC8..12 / PD2` 切为 `GPIO_MODE_ANALOG`；短按 `ASA` 唤醒时统一 `sd_try_mount()` 自动适配休眠期拔卡/插卡/换卡并无回滚地回写走时。
- **两阶段自适应降耗**：
  - **阶段 1（浅休眠，前 5 分钟）**：`HCLK = 1.0 MHz (HSI/8)`，门控关闭 `FSMC`/`DMA1`/`ADC1`/`USART1`/`AFIO` 及 `GPIOA/B/C/E/G` 时钟、停放 `PG1..8`/`PF6..9`/`PA8` 至 `ANALOG`、关断 OV7725 6× PLL（`COM4=0x01`），保留 100 Hz Gamma-2.0 平滑呼吸灯。
  - **阶段 2（深度休眠，满 5 分钟无缝降档）**：零闪烁降至 **`500 kHz (HSI/16)` + `TIM6 20.000 Hz`（`0.0 ppm`）**，LED 切为每 4.00 s 单闪 50 ms（`1.25%` 占空比），每 60 s 巡检轻载电量 `< 3.30V`（对齐实验五 `0%` 轻载与 `3.20V` 回弹实测）时静默转入亏电双闪休眠；亏电休眠同步升级至 `500 kHz / 20 Hz`，回电 `≥ 25%` 无缝交接阶段 2 深度休眠。

### 3. 全模态电源看门狗与坏卡/无卡分级菜单救卡
- `c3m1_power_service_modal()` 覆盖开机设表、主菜单及全部子弹窗、照片回看与删图确认框，自动执行 `< 3.20V` 强制低电休眠与 `AUTO SLEEP`（开机设表休眠唤醒完整保留走时且不误写旧快照）。
- 放开未挂载 SD 卡拒进菜单限制：插卡但未格式化/损坏时底栏显示 `BAD SD`，可直接进菜单执行 `FORMAT SD` 救卡（失败分支严格同步 `ctx->sd_ready`）；无卡时底栏显示 `NO SD`，可查看 `SYSTEM INFO`、切换 `COUNTER FMT` 及 `RAM ONLY` 临时调参。

### 4. 画质修正、性能提速与工程加固
- **色彩与 HDR/JPEG 修正**：单帧 JPEG、取景 LUT 与 4X DNG 回看统一按 `min(wb_r, 256, wb_b)` 每帧一次归一白点，根治 `3200K` 暖光高光青斑与 `B&W RED` 亮部封顶不足；`H16` `BaselineExposure` 拓宽至 `±7.00 EV` 并锚定中帧 `ref_white`；修复慢门 HDR/AEB `CLKRC`、手动 `0 EV` EXIF 与 VSYNC 超时传播；快门计数延后至写入并 `f_close` 成功后提交，失败自动 `f_unlink`。
- **取景 / HDR / JPEG / 回看提速与降栈**：`raw_demosaic_1x1_to_buf` 2× 展开实现 0 溢出、`vf_chroma_vig_pack_rgb565` 单寄存器 `g_q8`、`lcd_show_char`/`lcd_draw_rectangle` 流式 FSMC 并修 `y0+size==240` 截断、全屏 `320×240` 半透明快门定格、`TOP_HUD_W=104`、对称 `PEAK_STEP_2D`；HDR Pass 1 `4,096 B` 对齐 + `256 B` carry + Pass 2 `batch_pairs`；灰度 JPEG 1X 回看补齐 4 行条带 DMA、回看按 `(date_packed, num, variant)` 排序剪枝、旧版 DNG 同步支持黑白/HDR 渲染；大跨度菜单滑条 5× 快速加速、未改值免写卡并全处支持 `ASA` 长按返回；`Makefile` 新增 `DEBUG_LOG ?= 0` 默认门控生产态串口日志（省 `~6.6 KB` Flash）。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.16.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.16.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.16.hex`（或 `c3m1_camera_v0.1.16.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，`TP4056` 无 Power-Path 负载分离电路；虽然两阶段深度休眠与休眠关 SD 已将软件侧功耗压至极低，但受机械开关 `SW4` 后级 `AL422B`、`AMS1117` 与 `12 MHz` 有源晶振常供电限制，待机底流无法降为 0；日常长时间充电或超过一两天存放仍建议先长按 `ASA` 休眠落盘时间，再**拨断物理电源开关 `SW4`**。
- 主板 AL422B `/RE` 引脚硬接地且 `Q2 (AMS1117-3.3V)` 输出电容 `C34` 仅 `1 µF`，固件严格保持非并发帧锁（`g_vsync_state == 2`）以确保零错色成像。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数存内部 Flash 只增不减，支持 `STOCK / WEAR-LVL` 无损切换，固件不提供任何计数清零功能。
