# C3M1 Firmware v0.1.3 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本新增 **纯英文菜单系统、SD 卡二进制配置固化（含版本与 CRC-32 校验 + 断电记忆 ISO）、机内格式化 SD 卡** 以及 **白玉楼制作所 0.5s 极简开机动画**，并对文档结构进行拆分重构。

## 核心更新

### 1. 纯英文菜单系统与 4 段可配置 P 曲线
- **交互设计**：在已插卡取景界面**长按 `KEYISO (ASA)` ≥ 600 ms** 进入菜单（无 SD 卡时拒绝进入并提示 `NO SD CARD!`；菜单内热拔卡自动安全退出并卸载文件系统）。使用快门波轮跨 `15↔0` 滚动选择、`KEYSHOT` 循环切换/确认、`ASA` 短按返回/退出（退出时自动等待按键松开防误拍，并同步波轮当前物理刻度）。
- **8 项核心菜单**：
  - `MAX AUTO ISO`（`400 / 800 / 1600`）：设置自动 ISO 上限；
  - `MIN AUTO SHT`（`1/100 / 1/50 / 1/25 / 1/15 / 1/8`）：设置自动快门最慢下限，慢于 `1/50` 时取景保 15F、拍照自动走原子慢门；
  - `ANTI-FLICKER`（`50HZ / 60HZ / OFF`）：动态切换室内工频抗频闪 P 曲线折点；
  - `BATTERY DISP`（`VOLT / PCT`）：底栏电量显示在电压 `3.xxV` 与 10 段锂电百分比 `xx%` 之间切换；
  - `FILM LEVER`（`ON / OFF`）：实时开关过片扳手上弦约束；
  - `FORMAT SD`：开启 FatFs `FF_USE_MKFS=1`（复用 4 KB 写盘静态缓冲，零额外 RAM），NO/YES 二次确认且 `<3.25V` 低电禁格，按容量自动格式化为 FAT32/exFAT 并重建 `/CAYE_CAM` 与配置；
  - `SYSTEM INFO`：查看文件系统类型、SD 总/余容量、快门计数、电池电压与百分比、配置路径及固件版本哈希；
  - `EXIT MENU`：退出返回实时取景。
- **版本与短哈希底栏**：菜单底栏与开机界面统一显示固件版本号与 Git 短哈希（未提交修改自动附带 `-dirty`，由 `Makefile` 自动生成 `build/fw_version.h`）。

### 2. SD 卡二进制配置固化（`0:CAYE_CFG/c3m1.cfg`）与 ISO 断电记忆
- 所有菜单项及**关机前最后一次 ISO 模式**以定长 32 字节二进制格式保存在 SD 卡 `CAYE_CFG/c3m1.cfg`（短按切换 ISO 带 1.2s 防抖落盘，拍照/进菜单前强制刷盘）。
- 读取时依次执行 6 重校验：**文件长度 == 32 B → `C3M1` 魔数与结构版本 → 固件版本号（`major.minor.patch`）匹配 → IEEE 802.3 CRC-32 → 字段枚举范围**；跨版本升级或文件损坏时自动回退默认值并重建合法配置。

### 3. 白玉楼制作所 0.5s 开机动画与文档重构
- **极简低开销开机动画**：包含白玉楼制作所 32×27 像素徽标（归白玉楼制作所所有）与开源字体 Google Noto Sans CJK SC DemiLight（SIL OFL 1.1）光栅化的「白玉楼制作所」6 枚 24×24 点阵字模，全模块仅占 **~1 KB Flash、0 B 静态 RAM**；动画后半段与 SD 挂载/传感器初始化并行，无额外启动延迟。
- **快门计数约定**：与原厂固件保持一致，快门计数存内部 Flash 只增不减，固件不提供任何计数清零功能。
- **文档拆分**：将编译与烧录指南独立拆分为 [BUILD.md](../../BUILD.md)，[README.md](../../README.md) 聚焦使用与菜单说明。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.3.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.3.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.3.hex`（或 `c3m1_camera_v0.1.3.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 机身无 RTC 硬件，文件修改日期固定为 `2026-12-26`，DNG `DateTime` 标签固定为 `2026:08:17 00:00:00`。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
