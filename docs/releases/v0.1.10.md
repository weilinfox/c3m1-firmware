# C3M1 Firmware v0.1.10 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本带来**回看三态快门切换（含索尼微单风格 `INFO` 四通道直方图详情页）**、**按日期 `YYYYMMDD` 分目录存储**，并从硬件电路层面根治了 16 档 BCD 拨盘在高位档的电压跌落与回看翻页乱跳问题。

## 核心更新

### 1. 回看 `1X` 短按快门三态循环 & 索尼风格 `INFO` 详情页
- **三态循环（`CLEAN → CLIP → INFO → CLEAN`）**：进入回看默认为纯净 `1X` 全图（无斜纹叠加）；短按**快门（`SHOT`）**依次切换：
  1. **纯净 `1X` 全图**（底栏提示 `SH:CL`）；
  2. **`1X` 溢出标注（`CLIP`）**：全屏叠加 45° 红/蓝高光欠曝斜纹，底栏亮橙色 `CLIP`（提示 `SH:IN`）；
  3. **索尼风格详细信息（`INFO`）**，底栏亮青色 `INFO`（提示 `SH:1X`）：
     - **左上角 `160×120` 缩略图**：DNG 嵌入预览原生 1:1 零缩放直出（旧无预览 DNG 与直出 JPEG 同步缩放），同步叠加红/蓝 `CLIP` 溢出斜纹；
     - **右侧 `Y / R / G / B` 四通道 64 档直方图**：与缩略图等高对齐，含四等分暗网格线、中间调归一化与左右边缘溢出警示线；
     - **下方参数区**：展示日期目录与文件名、格式、EXIF/文件系统拍摄时间、分辨率/位深与白平衡色温、文件大小（`DNG+JPG` 双显）以及实时高光/暗部溢出占比与平均亮度。
- 翻页与从 `4X` 放大返回后自动保持当前显示模式；`4X` 放大看细节时保持纯净像素。

### 2. 照片按 8 位日期目录（`CAYE_CAM/YYYYMMDD/`）自动归档
- **拍摄自动按日分目录**：每次拍照读取软件时钟日期并自动创建 `0:CAYE_CAM/YYYYMMDD/`，`DNG+JPG` 同帧共享同一日期目录防止跨午夜分裂。
- **回看跨目录无缝扫描与向下兼容**：自动扫描 `CAYE_CAM/YYYYMMDD/` 下所有合法 8 位日期子目录，同时向下兼容历史直接存放在 `CAYE_CAM/` 根目录的照片（零新增静态 RAM，索引容量 800 张）；删除最后一张照片后自动清理空日期目录。

### 3. 根治 16 档 BCD 波轮翻页乱跳与代码审查加固
- **单脚分时下拉采样消除硬件分压跌落**：针对顶板 `SW6 (TSR-16 LG)` 公共端 `10 kΩ` 上拉与 STM32 四脚内部 `40 kΩ` 下拉并联导致高位档（`7/11/13/14/15`）电平跌落至 `~1.4~1.88 V` 临界值的问题，改用单脚分时下拉采样（其余 3 脚暂切高阻浮空），将全部 16 档高电平抬升至稳定的 `~2.5~2.64 V`。
- **连续多采样防抖与阻塞重置**：BCD 拨盘消抖升级为 `55 ms` + 连续 `≥ 3` 次一致采样，回看每次读卡渲染结束自动重置消抖窗口，彻底消除先断后通（Break-Before-Make）跨进位瞬态码导致的跳两张与乱序翻页。
- **回看交互与容错细节修复**：`1X` 退回看及删图取消弹窗同步支持长按过片扳手/按键事件；`DNG+JPG` 删图仅清除实际删除成功的标志位，防止部分失败残留孤儿文件；校验 EXIF `DateTime` 数字位合法性以确保空白字段正确回退 FatFs 时间；`DNG+JPG` 中 `.dng` 损坏时自动回退显示 `.jpg`；链接脚本 `_Min_Stack_Size` 提升至 `0x1000`。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.10.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.10.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.10.hex`（或 `c3m1_camera_v0.1.10.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，`SW4` 闭合时休眠电池侧仍余约 `~45 mA` 静态电流；建议关机前先**长按 `ASA` 休眠落盘时间**，再拨断物理开关 `SW4`。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
