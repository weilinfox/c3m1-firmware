# C3M1 Firmware v0.1.8 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本补齐机身的**软时钟时间系统、低功耗呼吸灯休眠与安全关机时间落盘闭环**：开屏动画直接显示精确到秒的固件构建时间，支持开机两页式日期/时间设定并自动同步写入 DNG/JPEG EXIF 与 SD 卡文件系统时间；新增自动/手动息屏休眠（`LED1` 100 Hz 呼吸灯、短按 `ASA` 秒醒），重新梳理顶板长按逻辑（长按 `4X` 进菜单、长按 `ASA` 休眠并保存时间），同时将曝光补偿收敛为严格物理精确的 `±2.0EV`。

## 核心更新

### 1. 软件时间系统、开屏构建时间与 EXIF / 文件系统时间戳
- **开屏构建时间显示**：构建期由 `Makefile` 自动注入本地构建时间，开屏动画版本号后完整显示 `v0.1.8 (<hash>) YYYY-MM-DD HH:MM:SS`。
- **两页式开机时间设定（`BOOT CLOCK`）**：
  - 菜单新增 **`BOOT CLOCK`**（`ON / OFF`，默认 `ON`）；开启时每次开机进入两页 24 px 大字设时界面：**`SET DATE (1/2)`**（4 位年-月-日，自动适配闰年与大小月）→ **`SET TIME (2/2)`**（时:分:秒），**波轮调数、快门确认下一项、`4X` 返回上一项**。
  - 首次开机以固件构建时间为初值，之后自动以 SD 卡保存时间为初值；关闭 `BOOT CLOCK` 时跳过设时并直接以构建时间为基准运行。
- **全链路时间戳记录与持久化**：
  - FatFs 启用 `get_fattime()`，新拍摄的 DNG / JPEG 文件修改时间自动记录当前时钟；DNG `DateTime (0x0132)` 与直出 JPEG 新增标准 **EXIF `APP1`**（`Make`/`Model`/`DateTime`/`DateTimeOriginal`/`DateTimeDigitized`）同步写入拍摄时间。
  - 开机确认时间、每次拍照后、进入休眠前、休眠唤醒后及任意配置保存均自动将最新时间刷新写入 SD 卡；低功耗休眠期间时钟仍按 1 秒节拍持续走时不丢时。

### 2. 低功耗呼吸灯休眠（`AUTO SLEEP`）与按键长按重映射
- **自动休眠与呼吸灯**：菜单新增 **`AUTO SLEEP`**（`5M / 10M（默认）/ 15M / 20M / 25M / OFF`）；超时进入休眠时关闭背光与 ST7789（`SLPIN`）、OV7725 进入软休眠（`COM2[4]=1` 并高阻 `PCLK` 让 `AL422B` 退回待机）、关闭 `ADC1` 与 HSE/PLL 降频至 **8 MHz HSI + `__WFI()`**，以 **100 Hz PWM + Gamma 2.0 曲线（3.0s 周期）** 驱动开漏 `LED1` 做平滑呼吸灯。
- **按键长按逻辑优化（便于关机前保存时间）**：
  - **长按 `4X` ≥ 600 ms**：进入菜单系统（短按 `4X` 保持切换 `1X / 4X` 放大）。
  - **长按 `ASA` ≥ 600 ms**：**手动立即进入休眠并保存当前时间与配置至 SD 卡**（随后可直接拨断物理开关 `SW4` 安全关机以保留准确关机时间）；休眠态**短按 `ASA`** 立即唤醒（自动吞掉唤醒按键不误切 ISO，首帧稳定绘完后再点亮背光零闪烁）。
- 同步在 `README.md` 与 `docs/architecture.md`（§3.10）补充主板电源树分析及为何当前硬件无法真断电软关机的说明。

### 3. 曝光补偿收敛至精确 `±2.0EV` & 配置 `schema v10`
- **`EXP COMP` 调整为 `-2.0EV ~ +2.0EV`（`1/3 EV` 步进，共 13 档）**：严格匹配 OV7725 相对 18% 中灰 `+2.43 EV` 的真实线性动态范围上限，消除原先 `+2.3/+2.7/+3.0EV` 触顶压缩虚标，标尺弹窗同步优化为宽距 **`-2  -1  0  +1  +2`**。
- 二进制配置 `0:CAYE_CFG/c3m1.cfg` 扩展至 40 字节对齐（`schema v10`，新增持久化 `auto_sleep`、`boot_clock` 与 `saved_epoch`），升级至 `v0.1.8` 首次开机自动安全重建默认配置。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.8.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.8.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.8.hex`（或 `c3m1_camera_v0.1.8.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，`SW4` 闭合时休眠电池侧仍余约 `~45 mA` 静态电流；建议关机前先**长按 `ASA` 休眠落盘时间**，再拨断物理开关 `SW4`。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
