# C3M1 Firmware v0.1.17 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本重点根治 **`ISO 1600 / 3200` 低照度与高快门偏黄绿**（升级 **4 通道 `GRBG` 分段黑电平** + **无偏有符号灰世界 AWB**），新增 **`AUTO SHT LOCK` 临时自动快门锁**、`C3M1 4mm F2.1` 镜头预设及 **插空卡/格式化保留当前内存配置**，并在 `BUILD.md` 中补齐了 **免焊 MicroUSB 刷写线制作、实拍接线图与开关机供电接线差异**（静态 RAM `bss = 53,200 B`，峰值栈 `5,520 B < 6,144 B`，0 软浮点、0 `malloc`，固件体积详见文末 CI 构建表，全部改动均经四模型交叉只读审查 `PASS`）。

## 核心更新

### 1. 根治 `ISO 1600 / 3200` 低照度与高快门偏黄绿
- **4 通道 `GRBG` 分段黑电平（`c3m1_black_level_grbg12`）**：基于 `ISO 1600 / 3200`（`1/50s` 与 `1/4000s`）稳态暗帧及实拍暖光场景复标定，修正原线性模型在 `ISO 1600` 的过扣，并精准抵消 `ISO 3200`（`GAIN=0xFF` 精细增益段）全画面 480 行偶行（`G0 / R`）相对奇行（`B / G1`）约 `+16 ~ +23 ADU` 的暗电平分裂：
  - `ISO 100 → [25, 23, 23, 25]`、`ISO 800 → [35, 36, 34, 35]`、`ISO 1600 → [47, 51, 46, 47]`、`ISO 3200 → [95, 96, 75, 76]`；
  - 全链路贯通取景器 LUT（1× 模式精准对齐奇行 `G1`）、AWB/AE、DNG `0xC61A` 与缩略图、JPEG（3×3 / 5×5 / 畸变重采样）、HDR 与 1X/4X 回放。
- **无偏有符号灰世界 AWB**：移除原 `rl >= 8 && gl >= 8 && bl >= 8` 逐像素下限过滤（该门限在高 ISO 弱蓝光下会丢弃大部分低蓝像元、专挑正向蓝噪声尖峰统计，导致蓝增益被腰斩、画面发黄绿），改为对全部未过曝像元（`< 3920`）直接累加原始 12-bit 并在帧末一次性有符号扣黑（正负读出噪声精确抵消，全黑自动冻结不漂移）；暖光蓝增益上限放宽至 `1152 (4.50×)`（回放解析上限放宽至 `1536`），并叠加 `g_exposure_dirty_frames == 0U && g_ae_settle_frames == 0U` 守卫消除切档与 AE 调增益瞬态抖动。实拍验证 `ISO 1600 / 3200` 出片与取景色彩还原显著改善。

### 2. 新增 `AUTO SHT LOCK` 临时自动快门锁
- 在菜单 `HDR MERGE` 上方新增纯运行态开关 **`AUTO SHT LOCK`**（默认 `OFF`，不持久化至 `c3m1.cfg`）。
- 开启后锁定取景与全部拍摄模式（单拍/慢门/连拍/AEB/HDR/JSR）使用 `AUTO` 快门并忽略物理快门旋钮（菜单与回看仍正常使用旋钮导航），底栏 `SA:` 以青色提示当前处于快门锁定状态。

### 3. 新增 `C3M1 4mm F2.1` 镜头预设 & 插空卡/格式化保留内存配置
- **镜头预设**：原标配预设更名为 **`C3M1 6mm F1.6`**，新增 **`C3M1 4mm F2.1`**（`4mm / F2.1 / dist=0 / vig=0`，等效 `36mm`，完整兼容旧 `schema v19`），并同步拓宽菜单右列右对齐宽度至 `160 px`。
- **配置保留**：开机运行期间热插入空白/配置损坏的 SD 卡，或在菜单中执行 `FORMAT SD` 后，自动保留并写回当前内存中的 `g_cfg` 参数，不再被重置回出厂默认配置。

### 4. 刷写线制作教程与开关机接线区别（详见仓库 `BUILD.md`）
- 仓库 `BUILD.md` 新增 **免焊 MicroUSB 端子线 + 4 根杜邦线 + ST-Link V2** 的完整刷写线制作指南与实拍特写图（无需焊接即可稳定复接），并重点明确以下接线注意事项：
  - **线材要求**：务必选用 **非 OTG** MicroUSB 线（确保 `Pin 4 (ID)` 悬空、未与 `GND` 短接；5pin 免焊端子的 `S` 屏蔽脚保持悬空不接）。
  - **相机物理电源开关 `SW4` 关闭时（推荐）**：接齐 **`+ (3.3V)`、`D- (SWDIO)`、`D+ (SWCLK)`、`- (GND)` 共 4 线**，由 ST-Link `3.3V` 单独向主板 `VCC3.3` 供电，无双电源冲突且不受休眠影响（屏幕背光由电池升压轨供电，关机刷写黑屏属正常现象，刷完拔线再开机即可）。
  - **相机物理电源开关 `SW4` 开启时（电池供电）**：**仅接 `D- (SWDIO)`、`D+ (SWCLK)`、`- (GND)` 共 3 线，务必断开 `+ (3.3V)` 红线**，避免常见铝壳 ST-Link V2 的 `3.3V` 电源输出与主板 `AMS1117-3.3V` 直接并联产生压差反灌（仅原装 ST-Link / J-Link 等高阻 `VTref / TVCC` 电平检测脚调试器属于例外，开机刷写时仍需接 `VTref`）。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过外部 ST-Link / CMSIS-DAP 的 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`；关机接 4 线、开机电池供电断开 `3.3V` 仅接 3 线，详见仓库 `BUILD.md`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.17.hex`（建议同时下载 `SHA256SUMS.txt` 校验完整性）后执行：
```bash
shasum -a 256 -c SHA256SUMS.txt   # Linux 可用 sha256sum -c SHA256SUMS.txt
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.17.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.17.hex`（或 `c3m1_camera_v0.1.17.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板无 MCU 可控电源开关，`TP4056` 无 Power-Path 负载分离电路；受机械开关 `SW4` 后级 `AL422B`、`AMS1117` 与 `12 MHz` 有源晶振常供电限制，待机底流无法降为 0；日常长时间充电或超过一两天存放仍建议先长按 `ASA` 休眠落盘时间，再**拨断物理电源开关 `SW4`**。
- 主板 AL422B `/RE` 引脚硬接地且 `Q2 (AMS1117-3.3V)` 输出电容 `C34` 仅 `1 µF`，固件严格保持非并发帧锁（`g_vsync_state == 2`）以确保零错色成像。
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 快门计数存内部 Flash 只增不减，支持 `STOCK / WEAR-LVL` 无损切换，固件不提供任何计数清零功能。
