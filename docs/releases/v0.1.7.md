# C3M1 Firmware v0.1.7 (Pre-release)

> 本固件及发布说明完全由 AI 生成，仅针对个人开发与自用场景完成必要功能验证，未覆盖所有批次主板、屏幕、存储卡及外设组合。更多个人附件兼容与稳定性请自行评估测试，刷机前请务必备份原机固件。

本版本全面升级**取景视野、回看画质与自动测光体验**：将实时取景扩展为无裁切全屏 4:3（`320×240`）并采用半透明内联底栏，回看画面升级至 ST7789 18-bit RGB666 + 2×2 有序抖动满宽显示，新增 **3 种测光模式（`STD / CENTER / ETTR`）与中心测光取景框指示**，同时大幅提升 P 档自动测光收敛速度并修复从高速手动快门（如 `1/8000s`）切回 `AUTO` 时的曝光过冲。

## 核心更新

### 1. 全屏 4:3 无裁切取景与半透明内联 HUD
- **全屏 `320×240` 实时取景**：取消原底部 20 px 黑条裁切，完整展示传感器 4:3 全视野（1X 覆盖全部 480 行 RAW，4X 居中 `y=120..359`，`GRID 3X3` 水平三分线同步校准至 `y=79 / 159`）。
- **半透明内联状态栏**：底部 20 px 区域以 25% 压暗半透明方式随 DMA 行带逐行合成，完全零闪烁；状态栏区域自动跳过峰值对焦以保持文字清晰与帧率稳定。

### 2. 三种测光模式（`METER MODE`）与中心测光指示框
- **菜单新增 `METER MODE`**（位于 `EXP COMP` 正下方，持久化配置升级至 `schema v7`）：
  - **`STD`**：全局多区均衡测光（带高光防溢保护）。
  - **`CENTER`**：中央重点测光（中央区域 6× 权重，中心占总权重 67%，且取消全局高光拉低钳制以更好应对逆光主体），取景画面同步叠加 **75% 亮白内联中心测光框与中心十字准星**（`x=80..239, y=61..179`）。
  - **`ETTR`**：向右曝光测光（将第 98 百分位高光压至线性 ~85% 并结合过曝比例快速回拉，兼顾最大信噪比与高光保留）。

### 3. 回看升级至 18-bit RGB666 满宽显示与快速 DNG 放大
- **ST7789V3 18-bit RGB666（`COLMOD=0x66`）+ 2×2 Bayer 有序抖动**：回看照片色彩过渡显著平滑，消除暗部与渐变色带，退出回看自动恢复 16-bit RGB565 以维持取景 15 fps。
- **满宽 1X 与更快的 DNG 1:1 放大**：1X 回看完整铺满 `320 px` 屏幕宽度（去除两侧黑边），对新 DNG 嵌入的 `160×120` 预览图采用无除法整数 2× 缩放；DNG 1:1 放大改用无分支快速 8-bit 路径，平移响应更轻快。

### 4. P 档高速收敛与手动切 `AUTO` 过冲修复
- **高速事件驱动闭环 AE**：仅在写入 SCCB 寄存器后等待 1 帧稳定，场景切换零延迟响应，大偏差单步步进提升至 `±2.0 EV`、中等偏差 `±0.8 EV`，并修复 `ETTR` 极端过曝时收敛过慢的问题。
- **修复 `1/8000s → AUTO` 快门冲顶回落**：切入 `AUTO` 快门或 `AUTO ISO` 时按当前实际等效物理曝光量无缝映射至 P 曲线（固定 ISO 时承接当前快门），并在 AE 入口等待切档后的 2 帧脏帧排空，彻底消除切档爆白与快门冲顶回落。
- 消除 GCC 15 链接器 `RWX` 段告警，实现 **0 编译警告 + 0 链接警告** 构建。

## 烧录说明

> **安全警告（必读）**
> 1. 主板 MicroUSB (`USB1`) 的 `VBUS` 直连 **`VCC3.3`**，**严禁直接插入电脑 5V USB 口**！请仅通过 ST-Link / CMSIS-DAP 3.3V SWD 接口烧录（`Pin1=3.3V, Pin2=SWDIO, Pin3=SWCLK, Pin4=NRST, Pin5=GND`）。
> 2. **切勿使用 OTG MicroUSB 线**：`Pin4 (ID)` 直连 STM32 `NRST`，OTG 线内部将 `ID` 接地会导致芯片永久复位。请使用普通 4 芯非 OTG 线（悬空 `NRST`），并配合 `reset_config none`。

### OpenOCD + ST-Link（命令行）
下载附件中的 `c3m1_camera_v0.1.7.hex` 后执行：
```bash
openocd -f interface/stlink.cfg -f target/stm32f1x.cfg \
  -c "reset_config none; program c3m1_camera_v0.1.7.hex verify reset exit"
```

### STM32CubeProgrammer / J-Flash
- 接口选择 **SWD**，Reset Mode 选择 **Software system reset**；
- 刷写 `c3m1_camera_v0.1.7.hex`（或 `c3m1_camera_v0.1.7.bin` 指定起始地址 `0x08000000`）。

## 已知硬件说明
- 主板 SD 卡座 `CARD1` 的 `Pin 11 (WP)` 硬件悬空未接入 MCU，全尺寸 SD 卡侧面的物理 `LOCK` 拨片在本机上不生效。
- 主板 Type-C 充电口 `CC1`/`CC2` 共用单颗 `5.1k` 下拉，请使用 USB-A 转 USB-C 线或无 e-Marker 3A C-to-C 线充电。
- 机身无 RTC 硬件，文件修改日期固定为 `2026-12-26`，DNG `DateTime` 标签固定为 `2026:08:17 00:00:00`。
- 快门计数与原厂一致，存内部 Flash 只增不减，固件不提供任何计数清零功能。
