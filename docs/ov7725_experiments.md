# OV7725 RAW 模式片内压扩、黑电平温漂与机内多帧 HDR 实机实验记录

本文档记录在 **C3M1 (C3MarkI) 量产硬件** 上针对 OV7725 传感器进行的三项关键底层画质验证实验（原始测试 DNG 文件不入库，可通过对应实验 commit 复现，并配合 `scripts/` 下分析脚本复算）：

1. **实验一**：OV7725 片内 10-bit → 8-bit Gamma 压扩可行性与真 10-bit 域证明（实验 commit `1e1efaf` / 回退 `4e06fbb`）
2. **实验二**：OV7725 片内硬件 ABLC（`COM13`）冷机 vs 热机黑电平温漂标定（实验 commit `46ba9e8` / 回退 `d20b845`）
3. **实验三**：机内 `12B 2F` / `14B 3F` / `16B 4F` 多帧流式 HDR 动态范围与信噪比实拍对比（固件 commit `7990b33`）

---

## 实验一：OV7725 片内 10-bit → 8-bit Gamma 压扩验证

### 1.1 实验目的与方法
验证 OV7725 在 VGA RAW 输出模式下能否启用片内分段线性 Gamma（`GAM1..GAM15` + `SLOP`），并判断该 Gamma 究竟作用在 **10-bit ADC 线性域**（可救回 8-bit 截断丢失的暗部低 2 bit）还是仅作用在 **8-bit 域**（会出现直方图梳状空洞）。

- **实验固件**：`git cherry-pick 1e1efaf`（按一次快门在完全锁定曝光下连续输出 `GAM_G0.dng` ~ `GAM_G6.dng` 共 7 组寄存器组合）。
- **分析脚本**：[scripts/analyze_gamma_exp.py](../scripts/analyze_gamma_exp.py)
  ```bash
  python3 scripts/analyze_gamma_exp.py <含 GAM_G*.dng 的目录> --export-dng GAM_G4_linearized.dng
  ```

### 1.3 第二轮（欠曝暗部极限场景，`GAM_G0` vs `GAM_G4`）
手动 `ISO 100` 刻意压暗 2~3 档以测试暗部极低灰度区间：

- **`GAM_G0.dng`（线性 8-bit）**：全图均值 `36.75`，中位数仅 `6`；其中 **`114,700` 像素（全图 37%）** 挤在 `0, 1, 2, 3` 仅 4 级；暗部 `1..16` 仅有 **16 级**离散灰阶：
  - `hist[0..16]`: `[4769, 37177, 47146, 25608, 15617, 13497, 12416, 9490, 7962, 8511, 7331, 5702, 5365, 5032, 4236, 3471, 3053]`
- **`GAM_G4.dng`（10-bit 片内 Gamma 压扩）**：全图均值 `53.82`，中位数 `18`；原 `0..3` 展开为 `0..12` 连续 **13 级**；暗部对应区间 `1..42` 拥有 **42 级连续零空洞灰阶（2.62× 精细度）**：
  - `hist[0..24]`: `[809, 996, 1915, 11554, 11833, 10994, 26523, 13332, 9010, 15424, 6702, 4325, 8649, 7361, 3927, 6805, 3009, 6413, 5920, 3041, 4623, 1758, 4067, 3909, 2409]`

- **结论落地**（commit `c361b94`）：采用 `COM7=0x01 / DSP_Ctrl1=0x87 / DSP_Ctrl4=0x02` + 紧凑 8-bit 封装 + DNG Tag `0xC618 LinearizationTable`，单张文件从原厂 618 KB（含一半无效 `0x00` 填充）降至 **310 KB**（写卡提速 2×），同时暗部精度反超原厂至 **2.62×**；经 Adobe Camera Raw 实测拉曝光/阴影验证通过。

## 实验二：OV7725 片内 ABLC（`COM13`）冷机 vs 热机黑电平温漂标定

### 2.1 实验目的与方法
OV7725 上电默认 `COM13 (0x3E) = 0xE2`（片内光学暗像元自动黑电平校准），而原厂 RAW 配置将其写为 `0x00`（全部关闭）。本实验在严实遮光条件下，分别采集 **18.4°C 冷机（`test_blk_0`）** 与 **连续开机并升温后的热机（`test_blk_1`）** 暗帧，对比 `COM13 = 0x00` 与 `COM13 = 0xE6`（`Bit7/6/5/2` 全开）的暗电流漂移与通道一致性。

- **实验固件**：`git cherry-pick 46ba9e8`（按一次快门在全黑环境下连续拍 6 张 310 KB 自动还原 DNG，均在 10-bit 线性域 `0..1016` 统计 640×480 有效区四通道）。
- **分析脚本**：[scripts/analyze_blc_exp.py](../scripts/analyze_blc_exp.py)
  ```bash
  python3 scripts/analyze_blc_exp.py test_blk_0 test_blk_1
  ```

> 注：该次临时实验脚本中 `1S_100` 紧接在 `50_1600` 之后仅等待 2 次 VSYNC（少于正式慢门流程的 3 次），因此 `BLC_*_1S_100` 实际复测了 `ISO 1600` 稳定后的第二帧（可作为 `ISO 1600` 稳态对照）。

### 2.3 核心结论与工程参数
1. **原厂关闭 BLC（`COM13 = 0x00`）存在严重热机高 ISO 温漂**：冷机 `ISO 1600` 下 `G` 通道 70% 被截断为 `0` 且 `R/B` 偏高导致暗部发紫；热机后更恶化至 `G ≈ 82`、`R = B ≈ 126`（吞噬 ~12% 动态范围并产生严重洋红暗部雾霾）。
2. **开启片内硬件 ABLC（`COM13 = 0xE6`）彻底稳住暗电流温漂**：硬件光学暗像元在 10-bit Gamma **之前**完成减除，冷热温漂从 `+120` LSB 压缩到 **`±1.5` LSB 以内**，且 `G0/R/B/G1` 四通道完全均衡无偏色。
3. **动态黑电平标定模型（升级至 12-bit 精度 `0..4064`，消除极端拉曝光偏绿）**：
   - 在 10-bit 整数域下用统一 `BlackLevel = (6, 6, 6, 6)` 实拍 `ISO 100` 全黑暗帧（`CDI00570.dng`）时，四通道均值实测为 `G0=6.20, R=5.82, B=5.81, G1=6.25`：`G` 略高于 `6`（`+0.22`），而 `R/B` 略低于 `6`（`-0.18`，在有符号扣黑后归零），导致在 Camera Raw 里极端拉 `+5 EV` 时呈现轻微绿雾。
   - 将 `LinearizationTable` 整体放大 4 倍至 **12-bit 精度（`0..4064`，`WhiteLevel = 4064`，0.25-LSB 精细度，不增加 1 字节 DNG 体积）** 后，全部 6 组冷/热/实拍样本的四通道均值呈现稳定规律：
     - `ISO 100 (1×)`：`G ≈ 24.8`，`R/B ≈ 23.4`（`G - RB ≈ +1.0`）
     - `ISO 1600 (16×)`：`G ≈ 86`，`R/B ≈ 91`（`G - RB ≈ -4.5`）
   - 最终采用分通道动态模型（按 `GRBG` 写入 Tag `0xC61A` 并同步用于取景 LUT 与 AE/AWB）：
     - $\text{BL}_{G} = 21 + 4 \times \text{gain}_x$（`ISO 100 → 25`，`ISO 1600 → 85`）
     - $\text{BL}_{RB} = 19 + \lfloor 4.5 \times \text{gain}_x \rfloor$（`ISO 100 → 23`，`ISO 1600 → 91`）
   - 经 `CDI00570_neutral.dng` 在 Adobe Camera Raw `+5 EV` 复测验证，暗部绿雾彻底消失。

## 实验三：机内 `12B 2F` / `14B 3F` / `16B 4F` 多帧 HDR 动态范围实拍对比

### 3.1 实验条件与方法
- **验证固件**：commit `7990b33`（`v0.1.11` + `16B 4F`），`ISO 100` 三脚架固定大光比室内桌面场景（顶部高亮度冷白 LED 灯条 + 暗部黑色键盘/机身边框）。
- **测试分组**（共 22 个 DNG）：
  - **场景 1（基准快门 `1/100s`）**：单帧 10-bit（`CDI00704`）、`12B 2F`（`CDI00705`）、`14B 3F`（`CDI00707`）、`16B 4F`（`CDI00710`）。
  - **场景 2（基准快门 `1/50s`，整体偏亮 `+1 EV` 压测高光）**：`14B 3F`（`CDI00714`）、`16B 4F`（`CDI00717`）。
- **噪声与动态范围度量**：在相同 150 个 `8×8` 暗部块及最平滑 5% 暗块内，以同行相邻同色绿像素差分 $\sigma_G = \sqrt{\frac{1}{2N}\sum (G_{x+2} - G_x)^2}$ 估算实测噪声底，计算有效动态范围 $\mathrm{DR} = \log_2(\mathrm{WhiteLevel}_{\text{eff}} / \sigma_G)$ 与同暗区信噪比 $\mathrm{SNR} = 20\log_{10}(\mu_G / \sigma_G)$。

### 3.4 关键结论
1. **逐档动态范围增益符合传感器物理规律**：
   - `10-bit → 12B 2F`：暗部读出噪声主导，暗部 SNR 实涨 `+6.06 dB`（`+1.01 EV`）+ 高光 `+1.00 EV`，总有效 DR 实涨 **`+1.84 EV`**；
   - `12B 2F → 14B 3F`：高光再增 `+1.03 EV`，暗部进入散粒噪声过渡区（`+3.68 dB`），总有效 DR 再涨 **`+1.51 EV`**；
   - `14B 3F → 16B 4F`：理论容器跨度再增 **`+1.94 ~ +2.00 EV`**（`16× → 64×`），实拍高光实得 **`+0.96 EV`**（场景 2 将 `14B 3F` 仍残留的 `0.88%` 灯条死白完全拉回至 `0.00%` 并余留 `0.37 EV` 余量），暗部在散粒噪声主导区再增 **`+3.55 dB`（`+0.49 EV`）**，常规室内实测总有效 DR 净增 **`+1.21 ~ +1.45 EV`**（`1/100s` 组实测达 **`14.13 ~ 14.60 EV`**）；极暗夜景等读出噪声主导场景下暗部增益可进一步逼近满额 `+1.0 EV`（总增量趋近 `+1.8 ~ +1.9 EV`）。
2. **`WhiteLevel = 65535` 饱和边界表现正常**：OV7725 实测相邻帧有效增益比略高于名义 `4.00×`（约 `4.10×`，三步连乘约 `69×`），`1009 × 69` 触发 `UINT16_MAX = 65535` 钳位（仅裁掉 `-3 EV` 最顶部约 `0.09 EV`），`BaselineExposure` 仍精确锚定 `+2.99 ~ +3.00 EV`，全图无溢出、无色偏、无接缝。
