## 核心特性

- **常驻 RAW 微单化取景与零快门时滞**：
  - OV7725 开机初始化一次后全程常驻 `644×480` `GRBG` 片内 10-bit Gamma 压扩 RAW（`COM7=0x01`、`DSP_Ctrl1=0x87`、`DSP_Ctrl4=0x02`、`COM13=0xE6` 硬件 ABLC 防热机高 ISO 温漂、`COM3=0xD0` 硬件正向、`COM4=0x81` 6× PLL / 18 MHz PCLK / 45 fps / `20.9 ms` 卷帘扫描、`COM2=0x01` 柔和驱动防排线振铃），彻底消除取景↔拍照模式切换与软复位等待。
  - 取景器采用 `1.5 KB` 零等待 SRAM 查表（经 `s_inv_gamma_10` 还原 10-bit 线性光 + 动态扣黑电平 + 预览 Gray-World AWB + 10-bit 分数插值 IEC sRGB OETF + RGB565 打包）与 `DMA1` 双缓冲异步刷屏：`1X` 模式稳跑 **15 fps**，`4X` 模式直接裁切中心 `320×220` 做 `1:1` 原生像素对焦放大（零延迟瞬切）。
  - **快门 `1/8000 ~ 1/25` 与 `AUTO`**：预览即真实拍照曝光，按下快门 `0 ~ 22 ms` 真零时滞直接锁存并写出当前帧。
  - **慢门 `1/8s ~ 2s`**：取景保持 45 fps（由硬件 `GAIN` + 数字 LUT 补偿预览亮度，**全档位稳跑 15 fps**）；按下快门时在 VSYNC 边界原子切入真实低 ISO 慢门曝光，单帧锁存后自动切回高速预览。
- **高可靠 360 KB 含嵌入预览图 DNG 1.4 与直出 VGA JPEG**：
  - 严格先锁死 AL422B `FIFO_WEN = 0` 再执行文件 I/O 与 Flash 写入，彻底根除慢卡环形回绕断层撕裂。
  - **DNG 嵌入预览图（`IFD0` + `SubIFD`）**：相比原厂将线性 8-bit 零填充进 16-bit 容器的 `618 KB` 文件，本固件采用 **片内 10-bit Gamma 压扩 + 硬件 ABLC（`COM13=0xE6`）+ 紧凑 8-bit 封装 + DNG 12-bit 精度 `LinearizationTable`（Tag `0xC618`, `0..4064`）与分通道动态 `GRBG BlackLevel`**，并内嵌标准 **`160×120` 校准色彩 RGB 预览图（`IFD0`）**，单张约 **360 KB**（仍显著小于原厂 618 KB），实测暗部灰阶精细度达原厂 **2.62×**，系统文件管理器/手机相册原生可见缩略图，Adobe Camera Raw / Lightroom 自动线性还原。
  - **机内流式 VGA JPEG 直出与同帧双出**：内置纯整数 3×3 双线性解马赛克 + 校准 sRGB 色彩矩阵 + IJG 整数 DCT 软编 Baseline JPEG（`640×480` YCbCr 4:2:0 Q90，约 35~70 KB），支持在菜单 `FILE FORMAT` 切换 **`DNG`（默认）/ `DNG+JPG` / `JPG`**；`DNG+JPG` 复用 AL422B `/RRST` 读指针复位，从同一锁存帧按当前日期输出至 `/CAYE_CAM/YYYYMMDD/CDIxxxxx.dng` 与 `/CAYE_CAM/YYYYMMDD/CDIxxxxx.jpg`。
- **原生 SDXC / exFAT 存储支持（最高 2 TB）**：
  - 基于 **FatFs R0.15a**（开启 `FF_FS_EXFAT` + `FF_USE_LFN` + `FF_USE_MKFS`），兼容 FAT16 / FAT32 / exFAT，并修复 STM32F1 HAL SD 驱动（去除 3.3V 主控不适用的 `S18R`、防护 2 TB 边界 32-bit 溢出），支持 64 GB ~ 2 TB 出厂 exFAT SDXC 卡即插即用与 SDXC/SDHC 混插热插拔（已实机验证三星 EVO Plus 256 GB、雷克沙 1800x 128 GB UHS-II）。

## 操控说明

### 顶板物理控件
- **快门波轮 `TSR1/2/4/8 (PF6~PF9)`（16 档 BCD）**：
  - `0..8`：机顶刻度 `1/8000, 1/4000, 1/2000, 1/1000, 1/500, 1/300, 1/150, 1/100, 1/50`
  - `9..14`：扩展慢门 `1/25, 1/8, 1/4, 1/2, 1s, 2s`
  - `15`：`AUTO` 自动测光档（4 段可配置微单 P 曲线软件闭环 AE，底栏实时显示 `SA:1/xxx` 与 `IA:xxx`）
- **`KEYISO / ASA (PF1)`**：
  - **短按**（松手触发）：循环切换 ISO（`AUTO / 100 / 200 / 400 / 800 / 1600`），并自动防抖保存至 SD 卡，下次开机恢复上次 ISO 模式；**休眠态短按立即唤醒**（自动吞掉唤醒按键，不误切 ISO）。
  - **长按 ≥ 600 ms**：**手动进入休眠并保存当前时间与配置至 SD 卡**（熄屏、`LED1` 进入呼吸灯；此时可直接拨断物理电源开关 `SW4` 安全关机以保留准确关机时间，或随时短按 `ASA` 唤醒继续拍摄）。
- **`KEY4X (PF3)`**：
  - **短按**（松手触发）：瞬时切换 `1X` 全视野 / `4X` 中心 `1:1` 放大对焦。
  - **长按 ≥ 600 ms**：进入纯英文菜单系统（未插 SD 卡时拒绝进入）。
- **`FILMKEY (PF10)`**（过片扳手）：
  - **短拨**（松手触发）：过片上弦（未上弦时居中显示 `WIND FILM LEVER` 并静默忽略快门；可在菜单 `FILM LEVER` 中实时关闭）。
  - **长按 ≥ 600 ms**：进入**照片回看（Playback）**，默认从最新一张开始。
- **`KEYSHOT (PF2)`**：快门拍照（慢门档居中显示 `EXPOSING...`）。在 `12B 2F` 和 `14B 3F` 两种 HDR 模式下，按下快门后进入 3 秒脚架自拍倒计时（屏幕逐秒显示 `HDR DELAY 3s` → `2s` → `1s`，底栏显示 `DLY`，LED1 按慢闪→最后 1 秒快闪提示；期间按 `ASA` / `4X` 或拨动过片扳手可随时取消且不消耗快门计数）。

### 照片回看（Playback）
- **支持格式与 18-bit 显示**：自动扫描 `/CAYE_CAM/YYYYMMDD/` 日期子目录并向下兼容旧版 `/CAYE_CAM/` 根目录照片（最多索引最新 800 张），同目录同编号 `DNG+JPG` 自动合并为单张条目；优先全宽 4:3（无黑边）极速显示 DNG 嵌入 `160×120` 预览图，兼容历史无预览 DNG（2×2 流式解拜耳）与纯 VGA Baseline JPEG 直出；DNG 1X 与 1:1 放大均切换 ST7789V3 **RGB666（18-bit）+ 2×2 有序抖动** 显著消除 2 寸屏渐变色带。
- **1X 全图浏览**：
  - **快门波轮**：前/后翻看照片（支持首尾循环）。
  - **`快门` 短按**：三态循环切换显示模式（翻页与退出 4X 后均保持当前模式）：
    1. **纯净 1X 全图**（默认进入无叠加）；
    2. **1X 溢出标注（`CLIP`）**：画面叠加红斜纹（过曝高光）与蓝斜纹（死黑欠曝），底栏亮橙色 `CLIP`；
    3. **索尼风格详细信息（`INFO`）**：左上角显示 `160×120` 缩略图（同步叠加红蓝 `CLIP` 斜纹），右侧叠排显示 **`Y / R / G / B` 四通道 64 档直方图**（带四等分刻度与边缘溢出提示），下方展示目录文件名、格式、**曝光参数（快门时间 / ISO / 曝光补偿 EV / 白平衡色温）**、拍摄时间、分辨率/位深、文件大小以及实时高光/暗部溢出占比与平均亮度，底栏亮青色 `INFO`。
  - **`4X`**：进入 `1:1` 像素放大检查模式（DNG 直接流式解全尺寸 Bayer RAW，JPG 流式解码 ROI 区域，右上角带迷你视口框）。
  - **过片扳手短拨**：打开删图确认窗，默认选中 `NO`。波轮切换 `NO/YES`，快门确认，`ASA` 或再次拨动扳手取消并返回当前照片。确认删除后同时删除同名 `.DNG` 与 `.JPG`，`<3.25V` 低电保护禁删。
  - **`ASA`**：退出回看返回取景。
- **放大（Zoom 1:1）模式**：
  - **快门波轮**：上下平移；**`ASA`**：向左平移；**`快门`**：向右平移；再按 **`4X`**：退回 1X 回看；**短拨过片扳手**：打开当前照片的删除确认窗。取消后回到原放大位置，删除成功后以全图显示剩余照片。

### 软件时间系统（无硬件 RTC 方案）
机身无外部 32.768 kHz RTC 晶振与备用电池，本固件内置 2000–2099 闰年软件时钟，配合 SD 卡持久化让开机工作期间的照片与文件系统都能记录真实时间：
- **开屏构建时间**：开屏动画版本号后直接显示本次固件构建时间（`vX.Y.Z (<hash>) YYYY-MM-DD HH:MM:SS`）。
- **开机两页式设时（`BOOT CLOCK`）**：
  - 菜单 `BOOT CLOCK` 默认 `ON`：每次开机在动画结束后依次进入 **`SET DATE (1/2)`**（4 位年-月-日，自动适配闰年与大小月）→ **`SET TIME (2/2)`**（时:分:秒）；**波轮**调数、**快门**确认并跳下一项（连按快门即可直接沿用当前值）、**`4X`** 返回上一项。
  - **初值来源**：首次使用或未插 SD 卡时以**固件构建时间**为初值；之后自动读取 SD 卡 `c3m1.cfg` 中上次保存的时间为初值。
  - 若在菜单将 `BOOT CLOCK` 设为 `OFF`，开机将跳过设时界面，直接以**固件构建时间**为起点走时。
- **走时、照片写入与关机前存时**：
  - 正常取景时按系统滴答精准走时，进入低功耗呼吸灯休眠后仍按 `TIM6` 节拍每秒继续走时不丢时。
  - 拍摄产生的 **DNG**（`IFD0 DateTime` + `ExifIFD` 曝光时间 / `ISO` / `EV` 补偿 / `DateTimeOriginal`）、直出 **JPEG**（EXIF `APP1` 同套完整曝光与时间字段）以及 **SD 卡文件系统修改时间** 均实时写入当前时钟与拍摄参数。
  - **开机设时确认、每次拍照后、进入休眠前、休眠唤醒后及所有配置保存**都会自动刷新 SD 卡保存的时间；因物理开关 `SW4` 直断电池无法在断电瞬间写卡，日常关机建议先**长按 `ASA` ≥ 600 ms 进入休眠**落盘当前精确时间，再拨断物理开关 `SW4`。

### 状态栏与指示灯
- **满屏 4:3 取景、左上角透明计数与底部 20px 半透明 HUD**：实时取景覆盖完整 `320×240`（`640×480` 无裁切 4:3 全视野，无左右黑边）。左上角无暗底阴影内联叠加**卡剩余可拍张数**（按当前存储格式 / HDR 模式自动折算，超 `99999` 显示 `>99999`，`<50` 黄字、`0` 或无卡 `----` 红字）与右侧**拍摄模式标识**（`DNG` 青 / `D+J` 黄 / `JPG` 绿 / `H12` 青 / `H14` 青）；底部 `y = 220..239` 以 25% 半透明暗底内联叠加状态栏（零闪烁），依次显示快门（`S:/SA:`）、ISO（`I:/IA:`）、**实时测光 EV 偏差**（`+0.0EV` ~ `-5.0EV / +3.0EV`，相对 18% 线性灰，手动与自动档均生效；`±0.3EV` 内白字、`±1.3EV` 内黄字、超限红字、补偿生效青字）、**实时白平衡色温**（自动 `A5500K` 白字 / 锁定预设 `3200K`/`5500K`/`6500K` 黄字）、`4X` 放大标记、状态（`RDY`/`WIND`/`EXP`/`SAVE`/`NOSD`）与内部 `VREFINT` 自校准电池电量（菜单可选 `3.xxV` 电压或 `xx%` 百分比，`<3.60V` 黄、`<3.45V` 红、`<3.25V` 低电写卡保护、`<3.20V` 强制低电休眠）。快门计数（`#00001`）移至 `DEBUG INFO` 叠加层与 `SYSTEM INFO` 查看（与原厂固件一致，存内部 Flash 只增不减，固件不提供清零功能）。
- **`LED1 (PD9)`**：开漏输出适配 `VCC5.0` 供电 — **取景全灭 / 曝光与锁帧常亮 / 写卡 80 ms 闪烁 / 写卡异常快闪 3 次 / 自动休眠期间 100 Hz 呼吸灯**（休眠时短按 `ASA` 唤醒）。

## 菜单系统与配置（Menu & `CAYE_CFG`）

### 进入与交互
- **进入条件**：必须已插入并正常挂载 SD 卡；在取景界面**长按 `KEY4X (4X)` ≥ 600 ms** 即可进入纯英文菜单。未插卡时弹窗提示 `NO SD CARD!` 并拒绝进入；若菜单打开期间热拔 SD 卡，将立即安全退出并卸载文件系统。
- **操作映射**：
  - **旋转快门波轮**：上下选择菜单项（支持跨 `15↔0` 循环与滚动条翻页），在确认弹窗中切换 `NO / YES`。
  - **按 `KEYSHOT`（快门）**：循环切换当前设置项（即时保存至 SD 卡）或确认执行子操作。
  - **短按 `KEYISO (ASA)`**：返回上一级或退出菜单（退出时自动等待按键松开防误拍，并同步波轮当前物理快门刻度）。
- **版本与哈希底栏**：菜单最底部常驻显示当前固件版本号与 Git 短哈希（工作区未提交修改时自动带 `-dirty`，例如 `v0.1.2 (22a7691)`）以及配置状态（`CFG OK` / `SAVED` / `LOW BAT` / `SD ERR`）。

### 菜单项一览
| 菜单项 | 可选值 / 操作 | 说明 |
| :--- | :--- | :--- |
| **`FILE FORMAT`** | `DNG` / `DNG+JPG` / `JPG`（默认 `DNG`） | 存储格式：单 DNG（含嵌入预览图）、同帧 DNG+JPEG 双出、或单 VGA JPEG 直出 |
| **`HDR MERGE`** | `OFF` / `12B 2F` / `14B 3F`（默认 `OFF`，**不写配置**） | 脚架机内多帧流式 HDR 合成（仅运行态生效、关机自动复位 `OFF`，不改 `c3m1.cfg`）：全程**锁定当前 ISO、仅调节快门时间**（即使 EV 0 为 `ISO 3200` 也可正常靠延长快门完成 `+1/+2 EV` 包围，不撞增益上限，仅受 `1/23000s`–`2.0s` 硬件快门范围限制），完全沿用当前测光与曝光补偿，拍摄 `2` 帧（`-1/+1 EV` → 真 **12-bit** DNG）或 `3` 帧（`-2/0/+2 EV` → 真 **14-bit** DNG，约 `676 KB`）；同组文件以首帧编号命名（`CDIxxxxx_0/_1[/_2].dng` 及 `CDIxxxxx_hdr.dng`，含 `BaselineExposure` 与色调映射 `160×120` 预览图），快门计数按实际曝光帧数累计（`2F` +2、`3F` +3），开启时左上角模式显示青色 `H12`/`H14`。**画质建议**：因暗场 `AUTO ISO` 默认按手持防抖曲线优先拉高 ISO，上三脚架拍 HDR 时建议手动将 ISO 设为 `100` 或 `200` 以换取更低底噪与更高有效动态范围 |
| **`WHITE BAL`** | `AUTO` / `3200K` / `5500K` / `6500K`（默认 `AUTO`） | 白平衡：自动白平衡、灯光卷（`3200K`）、普通胶片（`5500K`）、日光卷（`6500K`），同步作用于取景、DNG `AsShotNeutral` 与直出 JPEG |
| **`EXP COMP`** | `-2.0EV` ~ `+2.0EV`（`1/3 EV` 步进，默认 `+0.0EV`） | 曝光补偿（±2 档微单标尺弹窗：波轮左右微调、`4X` 一键归零、快门保存、`ASA` 取消），实时作用于自动测光（补偿生效且合焦时底栏 EV 亮青字） |
| **`METER MODE`** | `STD` / `CENTER` / `ETTR`（默认 `STD`） | 测光策略：全局 18% 灰（`STD`）、中央 50% 区域 3× 加权（`CENTER`，取景叠加四角测光框与中心十字）、或高光优先向右曝光（`ETTR`，保高光提暗部信噪比） |
| **`MAX AUTO ISO`** | `400` / `800` / `1600` / `3200`（默认 `1600`） | `AUTO` 自动 ISO 上限（`3200` 对应 OV7725 硬件最高 `31×` 增益；手动 ISO 保持最高 `1600`） |
| **`MIN AUTO SHT`** | `1/100` / `1/50` / `1/25` / `1/15` / `1/8`（默认 `1/50`） | `AUTO` 快门最慢下限；慢于 `1/50` 时取景仍保持 15F，拍照自动走单帧原子慢门 |
| **`ANTI-FLICKER`** | `50HZ` / `60HZ` / `OFF`（默认 `50HZ`） | 室内工频抗频闪折点（`50HZ: 1/100↔1/50`，`60HZ: 1/120↔1/60`，`OFF` 无阶梯） |
| **`PEAK COLOR`** | `RED` / `YELLOW` / `WHITE` / `BLUE`（默认 `RED`） | 索尼微单风格**常驻 2D 峰值对焦**高亮颜色（永远开启，自动随 ISO 调整抗噪阈值，`1X` 与 `4X` 放大均生效） |
| **`HISTOGRAM`** | `ON` / `OFF`（默认 `ON`） | 右下角 64 档实时迷你亮度直方图（`64×24 px`，高光截断 >2% 时右侧亮红线警示） |
| **`GRID 3X3`** | `OFF` / `ON`（默认 `OFF`） | `1X` 取景半透明三分构图线（`4X` 放大对焦时自动隐藏） |
| **`BATTERY DISP`** | `VOLT` / `PCT`（默认 `VOLT`） | 底栏电量显示格式：`3.xxV` 实时电压 或 10 段锂电百分比 `xx%` |
| **`FILM LEVER`** | `ON` / `OFF`（默认 `ON`） | 是否要求每次拍照前拨动过片扳手上弦 |
| **`AUTO SLEEP`** | `5M` / `10M` / `15M` / `20M` / `25M` / `OFF`（默认 `10M`） | 无操作自动息屏低功耗休眠（`LED1` 呼吸灯提示，短按 `ASA` 唤醒；因硬件无软开关，长时不用仍需拨断物理开关） |
| **`BOOT CLOCK`** | `ON` / `OFF`（默认 `ON`） | 开机时间设定开关：开启后每次开机分两页设定年月日与时分秒（波轮调数、快门确认下一项、`4X` 返回上一项，自动持久化至 SD 卡并同步写入照片 EXIF 与文件系统时间）；关闭时以固件构建时间为基准运行 |
| **`PB SKIP BRK`** | `OFF` / `ON`（默认 `OFF`） | 回看跳过 HDR 包围单帧：开启后，若同一组 HDR 存在合成片 `_hdr`，回看自动跳过同组 `_0` / `_1` / `_2` 直接浏览 `_hdr`（若 `_hdr` 缺失仍保留单帧可见） |
| **`FORMAT SD`** | `RUN >`（`NO / YES` 二次确认） | 机内格式化 SD 卡（自动按容量选 FAT32/exFAT，`<3.25V` 低电禁格，完成后自动重建 `/CAYE_CAM` 与配置文件） |
| **`DEBUG INFO`** | `OFF` / `ON`（默认 `OFF`） | 调试信息开关：开启后在直方图正上方内联显示实时取景帧率（`FPS: xx`）与快门计数（`SHT: xxxxx`），关闭时隐藏 |
| **`SYSTEM INFO`** | `VIEW >` | 查看文件系统类型、SD 总容量/剩余容量、当前快门计数、电池电压与百分比、配置路径及固件版本哈希 |
| **`EXIT MENU`** | `BACK` | 退出菜单返回实时取景 |

### 二进制配置文件（`0:CAYE_CFG/c3m1.cfg`）
- 所有菜单项与**关机前最后一次 ISO 模式及保存时间**统一以定长 **40 字节二进制格式**固化在 SD 卡 `CAYE_CFG/c3m1.cfg` 中（不消耗 STM32 内部 Flash 擦写寿命）。
- 每次开机或热插卡挂载时依次执行 5 重校验：**文件大小 == 40 B → `C3M1` 魔数与 `schema_ver` 结构版本 → IEEE 802.3 CRC-32 → 字段枚举范围**；只要结构版本未变更，跨版本升级固件**保留全部用户配置不重置**；仅当结构版本升级或文件损坏时自动安全回退默认值并重写有效配置。

## 硬件引脚对照与使用注意（C3MarkI 量产板）

| **顶板按键与机构** | `KEYISO`: `PF1`, `KEYSHOT`: `PF2`, `KEY4X`: `PF3`, `FILMKEY`: `PF10` (外置上拉低有效)；`TSR1/2/4/8`: `PF6~PF9` (内部下拉高有效 BCD) | 详见 `Drivers/BSP/KEY/` |
| **SDIO + 检测** | `D0~D3`: `PC8~11`, `CK`: `PC12`, `CMD`: `PD2`, `SDOK`: `PB7` (0=有卡) | 支持规范热插拔（TF 转 SD 请连同卡套整体插拔）；主板卡座 `Pin 11 (WP)` 悬空，SD 卡物理 `LOCK` 写保护拨片不生效 |

| **Type-C 充电** | `USB3 (TYPE-C 6P)` → `TP4056` | **① 线材兼容**：主板将 `CC1 (A5)` 与 `CC2 (B5)` 短接共用单颗 `5.1k (R20)`，插带 e-Marker 的 C-to-C 快充线会被 PD 头误判为音频配件拒绝供电，请使用 **USB-A 转 USB-C 线** 或无 e-Marker 的普通 3A C-to-C 线充电；<br>**② 切勿在开机或休眠状态（`SW4` 闭合）下长时间充电**：主板**无 Power-Path 负载路径分离电路**，`TP4056` `BAT` 脚直连电池与后级 `MT3608L`，且 `R_PROG = R13 + R14 = 2 kΩ`（恒流 `~600 mA`、满充截止电流仅 **`~60 mA`**，`TEMP` 脚直接地无 NTC 温控）。`SW4` 闭合休眠时后级电池侧仍有 `~45–65 mA` 负载，接近甚至超过 `60 mA` 截止阈值，会导致 **TP4056 无法正常判满截止（持续 4.20V 浮充过充）** 或在 `4.05V↔4.20V` 间反复微循环充放与发热；**日常充电请务必先长按 `ASA` 休眠落盘时间，再拨断物理开关 `SW4` 后充电**（详见 [docs/architecture.md](./docs/architecture.md) §3.10） |
| **物理电源开关** | `SW4 (XKB5858)` → `MT3608L` | **不支持真断电软件关机**：主板无 MCU 可控电源开关，`MT3608L`、`AMS1117-3.3`、`AL422B` 与 CMOS 12 MHz 有源晶振在 `SW4` 闭合时持续耗电（软件休眠电池侧仍余 `~45 mA`）；日常关机建议先**长按 `ASA` 进入休眠**（自动将当前时间与配置落盘至 SD 卡），再拨断物理开关 `SW4`（详见 [docs/architecture.md](./docs/architecture.md) §3.10） |
