## 核心特性

- **常驻 RAW 微单化取景与零快门时滞**：
  - OV7725 开机初始化一次后全程常驻 `644×480` `GRBG` 片内 10-bit Gamma 压扩 RAW（`COM7=0x01`、`DSP_Ctrl1=0x87`、`DSP_Ctrl4=0x02`、`COM13=0xE6` 硬件 ABLC 防热机高 ISO 温漂、`COM3=0xD0` 硬件正向、`COM4=0x81` 6× PLL / 18 MHz PCLK / 45 fps / `20.9 ms` 卷帘扫描、`COM2=0x01` 柔和驱动防排线振铃），彻底消除取景↔拍照模式切换与软复位等待。
  - 取景器采用 `1.5 KB` 零等待 SRAM 查表（经 `s_inv_gamma_10` 还原 10-bit 线性光 + 动态扣黑电平 + 预览 Gray-World AWB + 10-bit 分数插值 IEC sRGB OETF + 1.75× 色度增强 + RGB565 打包）与 `DMA1` 双缓冲异步刷屏：`1X` 全视野（`320×240`）叠加峰值对焦/直方图/HUD 实测 **9–10 fps**（开启 `INCAM DISTORT` 约 **8 fps**），`4X` 模式直接裁切中心 `320×240` 做 `1:1` 原生像素对焦放大（零延迟瞬切，实测约 **8 fps**）。
  - **快门 `1/8000 ~ 1/25` 与 `AUTO`**：预览即真实拍照曝光，按下快门 `0 ~ 22 ms` 真零时滞直接锁存并写出当前帧。
  - **慢门 `1/8s ~ 2s`**：取景保持传感器 45 fps（由硬件 `GAIN` + 数字 LUT 补偿预览亮度，**全慢门档位维持常规取景帧率不卡顿**）；按下快门时在 VSYNC 边界原子切入真实低 ISO 慢门曝光，单帧锁存后自动切回高速预览。
- **高可靠 360 KB 含嵌入预览图 DNG 1.4 与直出 VGA JPEG**：
  - 严格先锁死 AL422B `FIFO_WEN = 0` 再执行文件 I/O 与 Flash 写入，彻底根除慢卡环形回绕断层撕裂。
  - **DNG 嵌入预览图（`IFD0` + `SubIFD`）**：相比原厂将线性 8-bit 零填充进 16-bit 容器的 `618 KB` 文件，本固件采用 **片内 10-bit Gamma 压扩 + 硬件 ABLC（`COM13=0xE6`）+ 紧凑 8-bit 封装 + DNG 12-bit 精度 `LinearizationTable`（Tag `0xC618`, `0..4064`）与分通道动态 `GRBG BlackLevel`**，并内嵌标准 **`160×120` 校准色彩 RGB 预览图（`IFD0`）**，单张约 **360 KB**（仍显著小于原厂 618 KB），实测暗部灰阶精细度达原厂 **2.62×**，系统文件管理器/手机相册原生可见缩略图，Adobe Camera Raw / Lightroom 自动线性还原。
  - **机内流式 VGA JPEG 直出与同帧双出**：内置纯整数 3×3 双线性解马赛克 + 校准 sRGB 色彩矩阵 + IJG 整数 DCT 软编 Baseline JPEG（`640×480` YCbCr 4:2:0 Q90，约 35~70 KB），支持在菜单 `FILE FORMAT` 切换 **`DNG`（默认）/ `DNG+JPG` / `JPG`**；`DNG+JPG` 复用 AL422B `/RRST` 读指针复位，从同一锁存帧按当前日期输出至 `/CAYE_CAM/YYYYMMDD/CDIxxxxx.dng` 与 `/CAYE_CAM/YYYYMMDD/CDIxxxxx.jpg`。
- **原生 SDXC / exFAT 存储支持（最高 2 TB）**：
  - 基于 **FatFs R0.15a**（开启 `FF_FS_EXFAT` + `FF_USE_LFN` + `FF_USE_MKFS`），兼容 FAT16 / FAT32 / exFAT，并修复 STM32F1 HAL SD 驱动（去除 3.3V 主控不适用的 `S18R`、防护 2 TB 边界 32-bit 溢出），支持 64 GB ~ 2 TB 出厂 exFAT SDXC 卡即插即用与 SDXC/SDHC 混插热插拔（已实机验证三星 EVO Plus 256 GB、雷克沙 1800x 128 GB UHS-II）。

## 操控说明

### 顶板物理控件
- **快门波轮 `TSR1/2/4/8 (PF6~PF9)`（16 档 BCD）**：
  - `0..8`：机顶刻度 `1/8000, 1/4000, 1/2000, 1/1000, 1/500, 1/300, 1/150, 1/100, 1/50`
  - `9..14`：扩展慢门 `1/25, 1/8, 1/4, 1/2, 1s, 2s`
  - `15`：`AUTO` 自动测光档（4 段可配置微单 P 曲线软件闭环 AE，底栏实时显示 `SA:1/xxx` 与 `IA:xxx`）
- **`KEYISO / ASA (PF1)`**：
  - **短按**（松手触发）：循环切换 ISO（`AUTO / 100 / 200 / 400 / 800 / 1600`），并自动防抖保存至 SD 卡，下次开机恢复上次 ISO 模式；**休眠态短按立即唤醒**（自动吞掉唤醒按键，不误切 ISO）。
  - **长按 ≥ 600 ms**：**手动进入休眠并保存当前时间与配置至 SD 卡**（熄屏、`LED1` 进入呼吸灯；此时可直接拨断物理电源开关 `SW4` 安全关机以保留准确关机时间，随时短按 `ASA` 唤醒继续拍摄，或短按 **`SHOT` / `4X` / 过片扳手** 在屏幕右下角亮屏 `3 s` 速览当前最轻载电压与百分比 `x.xxV xxx%`）。
- **`KEY4X (PF3)`**：
  - **短按**（松手触发）：瞬时切换 `1X` 全视野 / `4X` 中心 `1:1` 放大对焦。
  - **长按 ≥ 600 ms**：进入纯英文菜单系统（未插 SD 卡时拒绝进入）。
- **`FILMKEY (PF10)`**（过片扳手）：
  - **短拨**（松手触发）：过片上弦（未上弦时居中显示 `WIND FILM LEVER` 并静默忽略快门；可在菜单 `FILM LEVER` 中实时关闭）。
  - **长按 ≥ 600 ms**：进入**照片回看（Playback）**，默认从最新一张开始。
- **`KEYSHOT (PF2)`**：快门拍照（慢门档居中显示 `EXPOSING...`）。在 `HDR MERGE`（`12B 2F / 14B 3F / 16B 4F`）与 `JSR BURST`（`7F / 14F / 30F`）模式下，按下快门后进入 3 秒脚架自拍倒计时（屏幕逐秒显示 `HDR/JSR DELAY 3s` → `2s` → `1s`，底栏显示 `DLY`，LED1 按慢闪→最后 1 秒快闪提示；期间按 `ASA` / `4X` 或拨动过片扳手可随时取消且不消耗快门计数）。`JSR BURST` 拍完亮帧后会自动弹窗提示完全遮挡镜头，再按快门拍摄同参数匹配黑场（按 `ASA` 可跳过）。

### 照片回看（Playback）
- **支持格式与 18-bit 显示**：自动扫描 `/CAYE_CAM/YYYYMMDD/` 日期子目录及 JSR 连拍子目录（`CDIxxxxx_7 / _14 / _30/`），并向下兼容旧版 `/CAYE_CAM/` 根目录照片（最多索引最新 800 条），同目录同编号 `DNG+JPG` 自动合并为单条；**每个 JSR 连拍目录折叠为 1 条回看记录**，选取首张亮帧（`CDIxxxxx.dng` 或 `CDIxxxxx_hdr.dng`）进行 1X / CLIP / INFO / 1:1 放大回看，底栏与 `INFO` 页以品红色明确标注拍摄类型（如 `JSR 14F`、`J14 H16` / `JSR 14F H16`），`INFO` 页额外统计目录内实际亮帧数、是否含黑场及总占用空间，删图时弹出 `DELETE JSR SET?` 整组删除整个连拍目录。优先全宽 4:3（无黑边）极速显示 DNG 嵌入 `160×120` 预览图，兼容历史无预览 DNG（2×2 流式解拜耳）与纯 VGA Baseline JPEG 直出；DNG 1X 与 1:1 放大均切换 ST7789V3 **RGB666（18-bit）+ 2×2 有序抖动** 显著消除 2 寸屏渐变色带。
- **1X 全图浏览**：
  - **快门波轮**：前/后翻看照片（支持首尾循环）。
  - **`快门` 短按**：三态循环切换显示模式（翻页与退出 4X 后均保持当前模式）：
    1. **纯净 1X 全图**（默认进入无叠加）；
    2. **1X 溢出标注（`CLIP`）**：画面叠加红斜纹（过曝高光）与蓝斜纹（死黑欠曝），底栏亮橙色 `CLIP`；
    3. **索尼风格详细信息（`INFO`）**：左上角显示 `160×120` 缩略图（同步叠加红蓝 `CLIP` 斜纹），右侧叠排显示 **`Y / R / G / B` 四通道 64 档直方图**（带四等分刻度与边缘溢出提示），下方展示目录文件名、格式、**曝光参数（快门时间 / ISO / 曝光补偿 EV / 光圈 F 值 / 白平衡色温）**、拍摄时间、**镜头焦距（原始标称 + `9×` 等效焦距 `EQ`）**、分辨率/位深、文件大小以及实时高光/暗部溢出占比与平均亮度，底栏亮青色 `INFO`。
  - **`4X`**：进入 `1:1` 像素放大检查模式（DNG 直接流式解全尺寸 Bayer RAW，JPG 流式解码 ROI 区域，右上角带迷你视口框）。
  - **过片扳手短拨**：打开删图确认窗，默认选中 `NO`。波轮切换 `NO/YES`，快门确认，`ASA` 或再次拨动扳手取消并返回当前照片。确认删除后同时删除同名 `.DNG` 与 `.JPG`，`<3.25V` 低电保护禁删。
  - **`ASA`**：退出回看返回取景。
- **放大（Zoom 1:1）模式**：
  - **快门波轮**：上下平移；**`ASA`**：向左平移；**`快门`**：向右平移；再按 **`4X`**：退回 1X 回看；**短拨过片扳手**：打开当前照片的删除确认窗。取消后回到原放大位置，删除成功后以全图显示剩余照片。

### 软件时间系统（无硬件 RTC 方案）
机身无外部 32.768 kHz RTC 晶振与备用电池，本固件内置 2000–2099 闰年软件时钟，配合 SD 卡持久化让开机工作期间的照片与文件系统都能记录真实时间：
- **开屏构建时间**：开屏动画版本号后直接显示本次固件构建时间（`vX.Y.Z (<hash>) YYYY-MM-DD HH:MM:SS`）。
- **开机两页式设时（`BOOT CLOCK`）**：
  - 菜单 `BOOT CLOCK` 默认 `ON`：每次开机在动画结束后依次进入 **`SET DATE (1/2)`**（4 位年-月-日，自动适配闰年与大小月）→ **`SET TIME (2/2)`**（时:分:秒）；**波轮**调数、**快门**确认并跳下一项（连按快门即可直接沿用当前值）、**`4X`** 返回上一项。
  - **初值来源**：首次使用或未插 SD 卡时以**固件构建时间**为初值；之后自动读取 SD 卡 `c3m1.cfg` 中上次保存的时间为初值。
  - 若在菜单将 `BOOT CLOCK` 设为 `OFF`，开机将跳过设时界面，直接以**固件构建时间**为起点走时。
- **走时、照片写入与关机前存时**：
  - 正常取景时按系统滴答精准走时，进入低功耗呼吸灯休眠后仍按 `TIM6` 节拍每秒继续走时不丢时。
  - 拍摄产生的 **DNG**（`IFD0 DateTime` + `ExifIFD` 曝光时间 / 光圈 `FNumber` / `ISO` / `EV` 补偿 / 焦距 `FocalLength` & `35mm` 等效焦距 / `DateTimeOriginal`）、直出 **JPEG**（EXIF `APP1` 同套完整曝光、镜头与时间字段）以及 **SD 卡文件系统修改时间** 均实时写入当前时钟与拍摄参数。
  - **开机设时确认、每次拍照后、进入休眠前、休眠唤醒后及所有配置保存**都会自动刷新 SD 卡保存的时间；因物理开关 `SW4` 直断电池无法在断电瞬间写卡，日常关机建议先**长按 `ASA` ≥ 600 ms 进入休眠**落盘当前精确时间，再拨断物理开关 `SW4`。

### 状态栏与指示灯
- **满屏 4:3 取景、左上角透明计数与底部 20px 半透明 HUD**：实时取景覆盖完整 `320×240`（`640×480` 无裁切 4:3 全视野，无左右黑边）。左上角无暗底阴影内联叠加**卡剩余可拍张数**（按当前存储格式 / 拍照模式 / HDR / JSR 连拍自动折算，超 `99999` 显示 `>99999`，`<50` 黄字、`0` 或无卡 `----` 红字）与右侧**拍摄模式标识**（`DNG` 青 / `D+J` 黄 / `JPG` 绿 / 连拍 `B:DNG`·`B:D+J`·`B:JPG` / 包围曝光 `AEB`·`AEB+J`·`AEBJ` 橙 / `H12`·`H14`·`H16` 青 / `JSR7`·`JSR14`·`JSR30` 或组合 `H16x14` 青）；底部 `y = 220..239` 以 25% 半透明暗底内联叠加状态栏（零闪烁），依次显示快门（`S:/SA:`）、ISO（`I:/IA:`）、**实时测光 EV 偏差**（`+0.0EV` ~ `-5.0EV / +3.0EV`，相对 18% 线性灰，手动与自动档均生效；`±0.3EV` 内白字、`±1.3EV` 内黄字、超限红字、补偿生效青字）、**实时白平衡色温**（自动 `A5500K` 白字 / 锁定预设 `3200K`/`5500K`/`6500K` 黄字）、`4X` 放大标记、状态（`RDY`/`WIND`/`EXP`/`SAVE`/`B001`/`AEB`/`NOSD`）与内部 `VREFINT` 自校准电池电量（菜单可选 `3.xxV` 电压或 `xx%` 百分比，`<3.52V` 黄、`<3.45V` 红、`<3.25V` 低电写卡保护、`<3.20V` 强制低电休眠）。快门计数（`#00001`）移至 `DEBUG INFO` 叠加层与 `SYSTEM INFO` 查看（与原厂固件一致，存内部 Flash 只增不减，固件不提供清零功能）。
- **`LED1 (PD9)`**：开漏输出适配 `VCC5.0` 供电 — **取景全灭 / 曝光与锁帧常亮 / 写卡 80 ms 闪烁 / 写卡异常快闪 3 次 / 普通休眠 100 Hz 平滑呼吸灯 / `<3.20V` 低电强制休眠每 3 s 双闪提示（表明 `SW4` 尚未断开，按任意顶键可复显提示）**。
- **电池电量监测与四档低电保护**：
  - **带载与休眠双放电百分比曲线**：开机取景带载电流约 `~350–420 mA`，扣除刚拔电表面虚电后以 `4.00V` 标定为 `100%`、以禁写 SD 临界 `3.25V` 标定为 `0%`（工作曲线 `3.25 / 3.38 / 3.49 / 3.55 / 3.59 / 3.63 / 3.68 / 3.74 / 3.82 / 3.91 / 4.00 V` 对应 `0%–100%`）；休眠按非唤醒键速览时处于最轻载（`~70 mA`，实测全工作段 `4.00V → 3.25V` 瞬时压差恒定 `+50 mV`），`adc_mv_to_percent_light()` 统一扣减 `50 mV`（等价 `3.30–4.05 V`）复用同一曲线，消除工作态与休眠态之间的百分比跳变。
  - **四档保护阈值**（仅在真实电池 `≥ 2.00V` 时生效，纯 ST-Link 供电不误触发）：`<3.52V` 底栏黄警（`~25%`）→ `<3.45V` 底栏红警（`~16%`）→ **`<3.25V` 锁死全部 SD 卡写入**（禁止拍照存卡、删片、格式化与写配置，菜单底栏明确显示红色 **`LOW BAT`** 而非 `SD ERR`）→ **`<3.20V` 强制低电休眠**（开机拦截、取景连续 2 次 2 s 采样触发、普通休眠唤醒复检三入口全覆盖：首次显示 15 s `LOW BATTERY! / SLEEPING (NOT OFF) / SWITCH OFF TO CHARGE`，息屏后 `LED1` 每 3 s 短双闪提醒电源开关仍未断开，按任意顶键可复显 5 s 提示，需拨断电源开关充电恢复）。

## 菜单系统与配置（Menu & `CAYE_CFG`）

### 进入与交互
- **进入条件**：必须已插入并正常挂载 SD 卡；在取景界面**长按 `KEY4X (4X)` ≥ 600 ms** 即可进入纯英文菜单。未插卡时弹窗提示 `NO SD CARD!` 并拒绝进入；若菜单打开期间热拔 SD 卡，将立即安全退出并卸载文件系统。
- **操作映射**：
  - **旋转快门波轮**：上下选择菜单项（支持跨 `15↔0` 循环与滚动条翻页），在确认弹窗中切换 `NO / YES`。
  - **按 `KEYSHOT`（快门）**：循环切换当前设置项（即时保存至 SD 卡）或确认执行子操作。
  - **短按 `KEYISO (ASA)`**：返回上一级或退出菜单（退出时自动等待按键松开防误拍，并同步波轮当前物理快门刻度）。
- **版本与哈希底栏**：菜单最底部常驻显示当前固件版本号与 Git 短哈希（工作区未提交修改时自动带 `-dirty`，例如 `v0.1.2 (22a7691)`）以及配置状态（`CFG OK` / `SAVED` / `LOW BAT` / `SD ERR`）。

### 菜单项一览
| 菜单项 | 可选值 / 操作 | 说明 |
| :--- | :--- | :--- |
| **`FILE FORMAT`** | `DNG` / `DNG+JPG` / `JPG`（默认 `DNG`） | 存储格式：单 DNG（含嵌入预览图）、同帧 DNG+JPEG 双出、或单 VGA JPEG 直出 |

### 二进制配置文件（`0:CAYE_CFG/c3m1.cfg`）
- 所有菜单项与**关机前最后一次 ISO 模式及保存时间**统一以定长 **44 字节二进制格式**（schema v16，支持从旧版 40 字节 v10–v14 与 44 字节 v15 无损迁移）固化在 SD 卡 `CAYE_CFG/c3m1.cfg` 中（不消耗 STM32 内部 Flash 擦写寿命）。
- 每次开机或热插卡挂载时依次执行 5 重校验：**文件大小（44 B 或旧版 40 B 兼容迁移）→ `C3M1` 魔数与 `schema_ver` 结构版本 → IEEE 802.3 CRC-32 → 字段范围**；只要结构版本未变更，跨版本升级固件**保留全部用户配置不重置**；仅当配置格式不兼容或文件损坏时自动安全回退默认值并重写有效配置。

### JSR 超分导入与 OV7725 满阱容量（Full Well Capacity, $e^-$）参考
使用 [Jiangtherapee-Super-Resolution-World-Best (JSR)](https://github.com/y-g-jiang/Jiangtherapee-Super-Resolution-World-Best) 导入 `CDIxxxxx_7 / _14 / _30/` 目录中的亮帧与 `CDIyyyyy_dark.dng` 黑场时，需按**单张输入 DNG** 对应的等效满阱电子数填写（基于 C3M1 OV7725 实机 `ISO 100 ≈ 18,000 e⁻` 估算；JSR 内部会自动累计 `7 / 14 / 30` 帧统计，**切勿再乘以连拍张数**）：

| ISO（增益） | 单帧 `10-bit` DNG | `12B 2F` HDR（`~4.1×`） | `14B 3F` HDR（`~16.8×`） | `16B 4F` HDR（`~65×`） |
| :--- | :---: | :---: | :---: | :---: |
| **`ISO 100` (`1×`)** | `18,000 e⁻` | `~74,000 e⁻` | `~302,000 e⁻` | `~1,170,000 e⁻` |
| **`ISO 200` (`2×`)** | `9,000 e⁻` | `~37,000 e⁻` | `~151,000 e⁻` | `~585,000 e⁻` |
| **`ISO 400` (`4×`)** | `4,500 e⁻` | `~18,500 e⁻` | `~75,500 e⁻` | `~292,000 e⁻` |
| **`ISO 800` (`8×`)** | `2,250 e⁻` | `~9,200 e⁻` | `~37,800 e⁻` | `~146,000 e⁻` |
| **`ISO 1600` (`16×`)** | `1,125 e⁻` | `~4,600 e⁻` | `~18,900 e⁻` | `~73,000 e⁻` |

> HDR 数值为暗部/中灰主导等效满阱（详见 [docs/architecture.md §3.12](./docs/architecture.md) 原理推导）；若大面积亮部场景下感觉高光降噪偏弱，可将 HDR 档填写值下调至表值的 `1/2 ~ 1/4`。
